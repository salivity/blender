Blender Geometry Nodes Dual Mesh Node Explained

The Dual Mesh node in Blender Geometry Nodes transforms a polygonal mesh by converting its faces into vertices and its vertices into faces. This article explains how the Dual Mesh node works, its primary procedural use cases—such as generating hexagonal grids, Voronoi patterns, and architectural wireframes—and the essential settings required to control its output effectively.

How the Dual Mesh Node Works

In mathematical geometry, a "dual graph" is created by placing a new point at the center of every existing face and connecting those points across adjacent edges.

The Dual Mesh node applies this concept to 3D geometry:

  • Faces become vertices: A single vertex is generated at the center of every original face.
  • Vertices become faces: Each original vertex is replaced by an n-sided polygon, where the number of sides matches the number of edges that originally connected to that vertex.
  • Edges are reconfigured: New edges are drawn between the new vertices, crossing over the midpoints of the original edges.

Primary Use Cases

1. Creating Hexagonal and Honeycomb Patterns

When applied to a standard triangulated mesh—such as an Ico Sphere or a subdivided plane converted to triangles—the Dual Mesh node converts triangles into hexagons and pentagons. This makes it the standard method in Blender for generating soccer ball patterns, geodesic domes, and honeycomb grids without manual modeling.

2. Procedural Voronoi Cell Generation

By combining point distributions (such as Poisson Disk sampling), Delaunay triangulation, and the Dual Mesh node, you can generate authentic 3D or 2D Voronoi cell layouts. This is commonly used for organic texturing, cracked surfaces, insect wings, and cellular structures.

3. Architectural Structures and Wireframes

The node is frequently paired with nodes like Extrude Mesh, Mesh to Curve, and Curve to Mesh to create complex architectural facades, sci-fi paneling, space frames, and procedural scaffolding.

Node Inputs and Settings

  • Mesh: The input geometry that you want to calculate the dual form for.
  • Keep Boundaries: A boolean toggle that dictates how the node handles the perimeter of non-closed surfaces. When enabled, it attempts to preserve the shape of the outer border by calculating partial faces along the boundary edges instead of trimming them.

Typical Workflow Example

A common procedural setup using the Dual Mesh node involves:

  1. Adding an Ico Sphere or a Grid node.
  2. Passing the geometry through a Triangulate node (if not already fully triangulated).
  3. Connecting the geometry to the Dual Mesh node to convert the triangular layout into a hexagonal mesh.
  4. Using an Extrude Mesh or Scale Elements node to inset, bevel, or extrude the resulting dual faces for the final model.
