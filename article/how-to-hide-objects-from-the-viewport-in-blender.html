How to Hide Objects from the Viewport in Blender

Hiding objects in Blender’s 3D viewport helps declutter your workspace and improve performance during complex 3D modeling projects. This guide covers the fastest methods to temporarily hide and unhide objects using essential keyboard shortcuts, the Outliner window, Local View mode, and viewport restriction toggles.

Using Keyboard Shortcuts

Keyboard shortcuts are the fastest way to toggle object visibility while working in the 3D Viewport.

  • Hide Selected Object: Select the object and press H.
  • Hide Unselected Objects: Select the object you want to keep visible and press Shift + H to hide everything else.
  • Unhide All Objects: Press Alt + H to reveal all previously hidden objects in the scene.

Using the Outliner Panel

The Outliner, located by default in the top-right corner of the interface, provides direct visual control over object visibility.

  1. Locate your object in the Outliner hierarchy list.
  2. Click the Eye icon next to the object’s name to toggle its visibility in the viewport.
  3. To hide an entire group of objects, uncheck the box or click the Eye icon next to the parent Collection name.

Using Local View (Isolation Mode)

If you need to work on a specific mesh without permanently altering the visibility settings of other scene elements, use Local View.

  1. Select the object or objects you want to focus on.
  2. Press the Numpad Slash (/) key (or the standard / key).
  3. Blender will temporarily isolate the selected items. Press / again to exit Local View and restore the previous layout.

Disabling Viewport vs. Render Visibility

Hiding an object with the H key or the Eye icon only removes it from your working viewport—it will still appear in your final render.

To control viewport and rendering behavior independently:

  1. Click the Filter dropdown (funnel icon) at the top right of the Outliner.
  2. Enable the Disable in Viewports (computer monitor icon) and Disable in Renders (camera icon) restriction toggles.
  3. Click the Monitor icon next to an object to completely disable it in the viewport, which reduces processing load on complex scenes.
  4. Click the Camera icon to prevent the object from appearing in final renders.
