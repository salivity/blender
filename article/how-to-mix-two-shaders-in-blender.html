How to Mix Two Shaders in Blender

Mixing shaders in Blender allows you to combine two distinct surface materials—such as metallic, glossy, diffuse, or glass—to create complex, realistic textures. By using the Mix Shader node in the Shader Editor, you can control the blending ratio using a simple slider value or a black-and-white texture mask. This guide provides a clear, step-by-step walkthrough on how to set up and control the Mix Shader node for your materials.

Step 1: Open the Shader Editor

  1. Select the object you want to apply the material to in the 3D Viewport.
  2. Switch your workspace to the Shading tab, or open a Shader Editor window.
  3. Click New at the top of the Shader Editor to create a new material if one is not already assigned.

Step 2: Add the Mix Shader Node

  1. Press Shift + A inside the Shader Editor to open the Add menu.
  2. Go to Shader > Mix Shader (or search for "Mix Shader").
  3. Click to place the Mix Shader node onto the workspace between your current nodes and the Material Output node.

Step 3: Connect Your Shaders

  1. Identify the two shaders you want to combine (for example, a Principled BSDF and a Glass BSDF). If you need a second shader, press Shift + A > Shader and choose another one.
  2. Connect the BSDF (green output socket) of your first shader into the top Shader (green input socket) of the Mix Shader node.
  3. Connect the BSDF output of your second shader into the bottom Shader input socket of the Mix Shader node.
  4. Drag the Shader output socket of the Mix Shader node into the Surface input of the Material Output node.

Step 4: Control the Shader Blend

The Fac (Factor) input on the Mix Shader node determines how much of each shader is visible:

  • Fac set to 0.0: Only the top shader is displayed.
  • Fac set to 0.5: An equal 50/50 blend of both shaders is displayed.
  • Fac set to 1.0: Only the bottom shader is displayed.

Using a Mask for Advanced Mixing

Instead of a uniform blend, you can use a image texture, noise texture, or color ramp to dictate where each shader appears:

  1. Press Shift + A and add a texture node (such as Texture > Noise Texture or Image Texture).
  2. Connect the Color or Factor output of the texture node into the Fac input socket of the Mix Shader node.
  3. Black areas in the mask will display the top shader, white areas will display the bottom shader, and gray areas will create a smooth transition between the two.
