How to Flip Face Normals in Blender

In Blender, face normals dictate which side of a polygon is considered the outside surface, directly affecting lighting, texturing, and rendering. Incorrect or inverted normals can cause dark patches, transparency glitches, or issues during 3D printing. This guide explains how to identify flipped normals, manually invert their directions, and automatically recalculate the orientation of an entire mesh using simple built-in tools and shortcuts.

How to Visualize Face Normals

Before flipping normals, it helps to see which direction they are currently pointing.

  1. Select your object and press Tab to enter Edit Mode.
  2. Click the Viewport Overlays drop-down menu in the top-right corner of the 3D Viewport.
  3. Check the Face Orientation checkbox.
    • Blue faces are pointing outward (correct direction).
    • Red faces are inverted and pointing inward.

Alternatively, you can scroll to the bottom of the Viewport Overlays menu and check the Normals icons under the Mesh Display section to draw line indicators extending from each face.

Flipping Specific Face Normals Manually

If only a few specific faces are facing the wrong direction, you can flip them manually:

  1. In Edit Mode, switch to Face Select mode by pressing 3 on your keyboard.
  2. Click to select the face (or hold Shift and click to select multiple faces) that needs to be flipped.
  3. Press Alt + N to open the Normals menu.
  4. Select Flip from the pop-up menu.

Alternatively, you can access this function by navigating to the top menu bar and selecting Mesh > Normals > Flip.

Recalculating All Normals Automatically

If your mesh has inconsistent orientation across many faces, Blender can automatically recalculate them:

  1. In Edit Mode, press A to select every face on the mesh.
  2. Press Shift + N to Recalculate Outside. Blender will automatically orient all faces outward.
  3. If you need all faces to point inward instead (such as for inverted interior rooms), press Shift + Ctrl + N to Recalculate Inside.

You can also access these auto-recalculation features by opening the Normals menu (Alt + N) and selecting Recalculate Outside or Recalculate Inside.
