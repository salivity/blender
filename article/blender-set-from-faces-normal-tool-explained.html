Blender Set From Faces Normal Tool Explained

The "Set From Faces" tool in Blender is a specialized normal-editing feature designed to control how light interacts with a 3D mesh's surface without altering its actual geometry. By forcing the custom split normals of selected vertices or edges to align perfectly with the orientation of their connected faces, this tool eliminates shading artifacts, creates flat-looking surfaces on low-poly models, and maintains clean shading on complex hard-surface objects. This guide details how the tool works, its practical applications in 3D modeling, and the exact steps to use it.

What Are Normals in Blender?

To understand "Set From Faces," you must first understand surface normals. A normal is an invisible vector perpendicular to a surface or vertex that tells Blender's rendering engine which direction light should bounce off.

  • Face Normals: The exact directional angle of a flat polygon.
  • Vertex Normals: Angles assigned to vertices, usually averaged across connected faces to create smooth shading.
  • Custom Split Normals: Manually overridden vertex normals that allow you to dictate shading angles per face corner, independent of automatic smooth shading.

The Set From Faces tool manipulates custom split normals.

What Does the "Set From Faces" Tool Do?

When you apply "Set From Faces," Blender takes the normal direction of the selected face (or faces) and applies that exact direction to all vertex corners connected to those faces.

Normally, when a mesh is set to "Shade Smooth," Blender averages the normals at shared vertices, creating smooth shading transitions across adjacent faces. Applying "Set From Faces" breaks this automatic averaging. It forces the shading vectors of the selected geometry to point in the same direction as the flat surface of the faces, resulting in completely flat, uniform lighting across those specific areas—even if the mesh as a whole uses smooth shading.

Key Use Cases

1. Hard-Surface Modeling Artifact Removal

When working with hard-surface models (like vehicles, machinery, or architectural assets), smooth shading can cause unintended shading gradients or "stretching" on flat surfaces near bevels or cutouts. Using "Set From Faces" on the main flat polygon forces its shading to remain completely flat, neutralizing light distortion caused by nearby dense or irregular geometry.

2. Game Asset Optimization

In game development, keeping polygon counts low is essential. Instead of adding extra support loops or bevels to fix shading issues on low-poly meshes, technical artists use "Set From Faces" to manipulate custom split normals directly. This achieves clean, high-poly-style shading on low-poly geometry without adding additional vertices.

3. Stylized and Low-Poly Art Styles

For stylized models where specific sections need flat, angular shading while adjacent sections remain smooth (such as gems, stylized foliage, or armor plates), "Set From Faces" provides precise control over which individual faces reflect light as flat surfaces.

How to Use "Set From Faces" in Blender

  1. Select the Mesh: Click on your 3D object in Object Mode and press Tab to switch to Edit Mode.
  2. Select Geometry: Switch to Face Select mode (3) and select the face or group of faces whose shading you want to flatten.
  3. Open the Normals Menu: Press Alt + N on your keyboard, or navigate to the top menu bar and select Mesh > Normals.
  4. Apply the Tool: Select Set From Faces from the menu.

Note: In Blender 4.1 and newer, custom normal data is handled dynamically through geometry nodes and standard modifiers, but the Alt + N > Set From Faces shortcut remains the direct way to apply fixed custom normal data to edit-mode selections.
