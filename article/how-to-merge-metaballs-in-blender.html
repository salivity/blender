How to Merge Metaballs in Blender

Merging metaballs in Blender is a unique process because these objects automatically blend together when placed near one another and share the same object family name prefix. This guide explains how automatic metaball merging works in Blender, how to control distinct metaball families, and how to permanently convert combined metaball structures into a single editable mesh.

Automatic Proximity Merging

In Blender, metaballs interact dynamically without needing a standard boolean or join operation.

  1. Press Shift + A and select Metaball to add your first metaball object (e.g., a Ball).
  2. Add a second metaball or duplicate the existing one (Shift + D).
  3. Move the metaballs close to each other in 3D space.

As long as the metaballs are near one another, their surface fields automatically cross-influence each other, creating a seamless, organic fusion.

Managing Metaball Families

Metaballs merge based on their naming convention. Blender identifies metaball families by the characters preceding the dot and numbers in their object name (such as Mball in Mball.001).

  • To merge metaballs together: Keep the default naming structure (Mball, Mball.001, Mball.002). They will fuse automatically when moved close together.
  • To prevent metaballs from merging: Rename the base prefix of the object in the Outliner or Item properties (e.g., change Mball.001 to GroupB.001). Metaballs with different family prefixes will pass through each other without blending.

Combining Metaballs in Edit Mode vs. Object Mode

  • In Edit Mode: Adding new metaballs while in Edit Mode keeps them within a single container object. Moving them close together blends them, and they remain easy to select as a unified group.
  • In Object Mode: Separate metaball objects will still automatically merge on screen if they share the same family prefix, but they remain individual selectable objects in your scene hierarchy.

Permanently Converting to a Single Mesh

If you want to freeze the metaball shape and edit its vertices directly, you must convert the live metaballs into a standard polygon mesh.

  1. Select the main metaball object in Object Mode.
  2. Right-click in the 3D Viewport to open the Object Context Menu.
  3. Select Convert To > Mesh (or go to Object > Convert > Mesh in the top menu bar).

Once converted, the organic blending behavior stops, and the combined surface becomes a single, editable 3D mesh object composed of vertices, edges, and faces.
