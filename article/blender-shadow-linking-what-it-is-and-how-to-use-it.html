Blender Shadow Linking: What It Is and How to Use It

Shadow linking is a rendering feature in Blender that allows artists to selectively choose which objects cast or receive shadows from specific light sources. This guide provides a concise overview of what shadow linking is, why it is used in 3D production, and the exact steps needed to set it up and customize it using Blender's Cycles render engine.

What Is Shadow Linking?

Shadow linking gives you direct creative control over shadow generation without altering the physical positions of lights or geometry. While standard lighting calculates shadows based on real-world physics, shadow linking allows you to break physical accuracy for artistic purposes.

Introduced in Blender 4.0 alongside Light Linking, this feature lets you:

  • Exclude specific objects from casting shadows under a particular light.
  • Prevent specific objects from receiving shadows cast by other objects.
  • Isolate dramatic or artistic shadows to key focal points without cluttering the rest of the scene.

Prerequisites

To use shadow linking, your scene must meet the following criteria:

  • Blender Version: Blender 4.0 or newer.
  • Render Engine: Cycles (Shadow linking is not supported in EEVEE).

How to Enable and Use Shadow Linking

Step 1: Set Your Render Engine to Cycles

  1. Open the Render Properties tab in the Properties editor.
  2. Set the Render Engine to Cycles.

Step 2: Access the Shadow Linking Panel

  1. Select the light source (Point, Sun, Spot, Area) or an emissive mesh in your 3D Viewport.
  2. In the Properties editor, navigate to the Object Properties tab (represented by an orange square icon).
  3. Scroll down and expand the Shading sub-panel.
  4. Locate the Shadow Linking section.

Step 3: Create a Shadow Linking Collection

  1. Click the New button under the Shadow Linking section to create a dedicated collection for the selected light.
  2. Open Blender's Outliner window alongside your properties panel, or use the object picker inside the panel.
  3. Drag and drop the target 3D objects from the Outliner directly into the Shadow Linking field.

Step 4: Configure Shadow Behavior

Once an object is linked, you can change how it interacts with the light's shadows:

  • Include Mode: Only the objects assigned to this list will cast or receive shadows from this light source.
  • State Toggle (Exclude): You can toggle individual objects inside the shadow link collection to "Exclude" by clicking the state icon next to the object name. This ensures that the light calculates shadows for all scene objects except the excluded ones.

Light Linking vs. Shadow Linking

While closely related, the two features handle different aspects of illumination:

  • Light Linking: Determines which objects receive direct illumination from a light source.
  • Shadow Linking: Determines which objects cast or block shadows generated by that illumination.

Combining both features provides complete artistic control over complex scene lighting, character isolation, and product visualization.
