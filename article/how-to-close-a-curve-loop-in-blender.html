How to Close a Curve Loop in Blender

Closing a curve loop in Blender is an essential technique for creating closed 2D shapes, outlines, and filled 3D geometry. This guide explains how to quickly bridge the start and end points of a Bezier or NURBS curve using the Toggle Cyclic feature via keyboard shortcuts, the viewport menu, and the Object Data Properties panel.

Method 1: Use the Keyboard Shortcut

  1. Select your curve object and press Tab to enter Edit Mode.
  2. Select any control point on the curve spline you want to close, or press A to select all points.
  3. Press Alt + C to toggle the cyclic state. Blender will automatically connect the starting and ending control points with a new segment, closing the loop. Pressing Alt + C again will open the loop back up.

Method 2: Use the Viewport Curve Menu

  1. Select the curve and switch to Edit Mode (Tab).
  2. Click on the Curve menu located in the top-left corner of the 3D Viewport header.
  3. Select Toggle Cyclic from the drop-down menu to close the open ends.

Method 3: Use the Object Data Properties Panel

  1. Select your curve and enter Edit Mode.
  2. Go to the Properties Editor on the right side of the screen and click on the Object Data Properties tab (represented by a green curve icon).
  3. Expand the Active Spline panel.
  4. Check the box labeled Cyclic U.

Connecting Two Specific Endpoints Manually

If you want to connect two separate endpoints of an open curve rather than toggling the main spline cyclic:

  1. Switch to Edit Mode (Tab).
  2. Select the two endpoint vertices you wish to join by holding Shift and clicking them.
  3. Press F to make a segment between the two selected control points.
