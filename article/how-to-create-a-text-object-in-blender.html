How to Create a Text Object in Blender

Creating text in Blender is a simple process that allows you to add custom 2D or 3D typography to your graphics, animations, and models. This step-by-step guide covers how to insert a text object, edit the wording, adjust the font and alignment, and extrude it into a 3D shape.

Step 1: Add a Text Object

  1. Open Blender and ensure you are in Object Mode (press Tab to switch if necessary).
  2. Position your 3D cursor where you want the text to appear.
  3. Press Shift + A to open the Add menu (or click Add at the top left of the 3D Viewport).
  4. Hover over Text and left-click. A flat text object displaying the word "Text" will appear on the grid.

Step 2: Edit the Text Content

  1. Select the text object by left-clicking on it.
  2. Press Tab to enter Edit Mode. A cursor will appear at the end of the text.
  3. Use the Backspace key to delete the default letters and type your desired message.
  4. Press Tab again to exit Edit Mode and return to Object Mode.

Step 3: Convert the Text to 3D (Extrusion)

  1. Select the text object in Object Mode.
  2. Go to the Properties Panel on the right side of the screen.
  3. Click on the Object Data Properties tab (represented by a green green letter "a" icon).
  4. Expand the Geometry rollout menu.
  5. Increase the Extrude value to add depth and make the text three-dimensional.
  6. Optional: To add smooth, rounded edges, expand the Bevel section underneath Geometry and slightly increase the Depth value.

Step 4: Change Fonts and Alignment

  1. Stay in the Object Data Properties tab (the green "a" icon).
  2. To change the font, expand the Font section, click the folder icon next to Regular, and browse to a .ttf or .otf font file on your computer.
  3. To align the text, expand the Paragraph section and adjust the Horizontal and Vertical alignment options (e.g., Center, Left, or Right). You can also adjust character and line spacing here.

Step 5: Convert Text to a Standard Mesh (Optional)

If you plan to perform advanced 3D modeling, sculpting, or mesh editing on your text, you must convert it from a parametric text object into a standard polygon mesh.

  1. Select the text object in Object Mode.
  2. Right-click in the 3D Viewport.
  3. Select Convert To > Mesh.

Once converted, you can no longer edit the typed text using Edit Mode, but you can manipulate individual vertices, edges, and faces like any standard Blender model.
