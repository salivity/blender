How to Solidify Faces in Blender Edit Mode

Solidifying faces in Blender’s Edit Mode allows you to give thickness to specific non-manifold surfaces or selected geometry destructively, giving you direct control over the resulting mesh structure. While the Solidify Modifier is typically used for entire non-destructive objects, using the dedicated Solidify Faces tool or Extrude commands in Edit Mode is ideal for quick, localized adjustments to your 3D models. This guide covers the exact steps to solidify selected faces directly within Edit Mode, along with alternative techniques for controlling thickness.

How to Use the Solidify Faces Tool

Blender features a built-in tool designed specifically to add thickness to selected geometry in Edit Mode.

  1. Enter Edit Mode: Select your object in the 3D Viewport and press Tab to switch to Edit Mode.
  2. Select Face Mode: Press 3 on your keyboard (not the Numpad) or click the Face Select icon in the top-left corner of the viewport.
  3. Select the Target Faces: Left-click to select a single face, or hold Shift and click to select multiple faces. Press A if you want to select all faces.
  4. Execute Solidify Faces:
    • Click Face in the top viewport menu bar, then select Solidify Faces.
    • Alternatively, press F3, type Solidify Faces, and press Enter.
  5. Adjust Parameters: Open the Solidify Faces operator panel in the bottom-left corner of the 3D Viewport to fine-tune your settings:
    • Thickness: Controls how much depth is added to the selected faces.
    • Offset: Determines whether the geometry expands inward (-1.0), outward (1.0), or evenly from the center (0.0).

Alternative Method: Extrude Faces Along Normals

If you want interactive control over face thickness using your mouse, extruding along normals is a fast alternative.

  1. Select your desired faces in Edit Mode.
  2. Press Alt + E to open the Extrude Menu.
  3. Select Extrude Faces Along Normals.
  4. Move your mouse to set the desired thickness, then left-click to confirm.
  5. (Optional) Check the Offset Even option in the bottom-left popup menu to ensure uniform thickness across corners.

Edit Mode Solidify vs. Solidify Modifier

  • Edit Mode (Destructive): Permanently alters the mesh geometry. Best used when you only need to add thickness to specific regions of a mesh without affecting the rest of the model.
  • Solidify Modifier (Non-Destructive): Applies thickness dynamically to the entire object or a designated vertex group. Best used when you need to adjust thickness later or maintain a clean, base mesh.
