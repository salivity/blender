What Is Active Element Pivot Point in Blender?

The Active Element pivot point in Blender is a transform reference setting that uses the last selected object, vertex, edge, or face as the absolute center for transformation tools like rotation, scaling, and mirroring. By focusing transforms around this specifically highlighted selection rather than the center of a group or the 3D Cursor, artists gain precise control over alignment, modeling geometry, and scene organization.

Understanding the Active Element

In Blender, when you select multiple items, the last item you select becomes the “Active Element.” It is visually distinguished from the rest of the selection by a lighter orange or white highlight.

When the Pivot Point mode is set to Active Element, all transformation operations (Rotate, Scale, Mirror) recalculate their center point around the origin or center of this specific active item, regardless of how many other items are selected.

Primary Uses of the Active Element Pivot Point

1. Rotating Multiple Objects Around a Specific Object

Instead of manually moving the 3D Cursor to an object’s location to act as a hinge, you can simply select all surrounding objects, select the hinge object last, set the pivot point to Active Element, and rotate. All selected objects will orbit seamlessly around the active object’s pivot center.

2. Precise Geometry Scaling in Edit Mode

In Edit Mode, scaling a group of vertices can cause unwanted shifting if scaled from the default Median Point. Setting the pivot point to Active Element allows you to select a reference vertex, edge, or face last. When you scale, the entire selection shrinks toward or expands away from that chosen reference point, keeping the active element’s relative position anchored.

3. Aligning Objects and Components

Active Element simplifies aligning elements along a single plane or axis: * Select the vertices or objects you want to align. * Select the target vertex or object last so it becomes active. * Scale along a specific axis to zero (e.g., S + Z + 0). * All selected elements will flatten directly to the Z-position of the active element without moving the active element itself.

4. Non-Destructive Assembly and Mechanical Rigging

When building complex hard-surface models—such as mechanical arms, doors, or robotic joints—you often need pieces to rotate around a specific bolt or pin. The Active Element pivot point eliminates the need to continuously re-position the 3D Cursor, speeding up test rotations and layout adjustments.

How to Enable Active Element Pivot Point

  1. Header Menu: Click the Pivot Point dropdown menu at the top center of the 3D Viewport (represented by an icon showing two connected dots) and select Active Element.
  2. Keyboard Shortcut: Press the Period (.) key on your keyboard to open the Pivot Point pie menu, then select Active Element (or press 4).

Active Element vs. Other Pivot Points

  • Median Point: Calculates the average center of all selected items. Moving or scaling affects everything relative to an arbitrary center.
  • Bounding Box Center: Uses the center of an imaginary box enclosing all selected objects.
  • 3D Cursor: Rotates or scales around the location of the 3D Cursor, requiring manual placement.
  • Active Element: Offers dynamic, targeted control based entirely on your last selection, requiring zero manual cursor placement.
