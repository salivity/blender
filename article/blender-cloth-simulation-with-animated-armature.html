Blender Cloth Simulation with Animated Armature

Combining a dynamic cloth simulation with an animated armature in Blender allows garments to deform naturally with character movement while reacting realistically to physics like gravity and inertia. This process involves rigging the clothing to the character's skeleton, establishing collision boundaries on the character mesh, defining pinned vertex groups to hold the cloth in place, and properly arranging the modifier stack.

Step 1: Set Up Character Collisions

Before introducing cloth physics, the character mesh must act as a physical barrier so the cloth does not clip through the body.

  1. Select your character mesh in the viewport.
  2. Navigate to the Physics Properties tab.
  3. Click Collision to enable collision physics on the body.
  4. Adjust the Outer Thickness and Inner Thickness under the Softbody & Cloth panel to ensure a slight gap between the skin and the garment, preventing unwanted clipping.

Step 2: Bind the Clothing to the Armature

The clothing mesh needs to follow the general movement of the character before the physics simulation is calculated.

  1. Select the clothing mesh, hold Shift, and select the character's Armature.
  2. Press Ctrl + P and select With Automatic Weights (or transfer weights from the character mesh using the Data Transfer modifier).
  3. Test the animation in Pose Mode to confirm that the clothing moves along with the character's limbs and torso.

Step 3: Create a Pinning Vertex Group

A pin group tells Blender which parts of the garment should strictly follow the armature animation and which parts should hang freely and simulate dynamic physics.

  1. Select the clothing mesh and switch to Weight Paint Mode or Edit Mode.
  2. Go to the Object Data Properties tab (green triangle icon) and create a new Vertex Group (e.g., named "Pin_Group").
  3. Assign a weight of 1.0 to areas that must stay attached to the body (such as waistbands, collars, or seams).
  4. Assign a weight of 0.0 (or leave unassigned) to areas meant to move freely (such as skirts, capes, or loose sleeves). Use weight painting gradients for smooth transitions.

Step 4: Configure the Cloth Simulation

Apply and configure the cloth physics on the garment mesh.

  1. Select the clothing mesh and open the Physics Properties tab.
  2. Click Cloth.
  3. Choose a preset (such as Cotton, Silk, or Leather) as a starting point.
  4. Scroll down to the Shape section.
  5. In the Pin Group field, select the vertex group created in Step 3.
  6. Scroll down to the Collisions section, check Object Collisions, and optionally enable Self Collisions to prevent the fabric from passing through itself.

Step 5: Arrange the Modifier Stack

The order of modifiers in Blender is critical for physics interacting with animated rigs.

  1. Go to the Modifier Properties tab (wrench icon) on the clothing mesh.
  2. Ensure the modifiers are ordered from top to bottom as follows:
    • Armature Modifier (Top)
    • Cloth Modifier (Middle)
    • Subdivision Surface / Solidify (Bottom, if applicable)

Note: The Armature modifier must be placed above the Cloth modifier so that the character movement positions the pinned vertices first, allowing the Cloth solver to calculate physics based on that motion.

Step 6: Bake and Review the Simulation

  1. Return to the Physics Properties tab on the clothing mesh.
  2. Scroll down to the Cache section.
  3. Set the Start and End frames matching your animation timeline.
  4. Click Bake.
  5. Once baking finishes, play back the timeline in the viewport to review the interaction between the animated armature and dynamic cloth.
