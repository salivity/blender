Blender Developer Extras and Experimental Features

The Developer Extras toggle in Blender is a specialized preference setting that grants access to internal development tools, advanced debugging menus, and cutting-edge experimental features. This article explains how to activate the toggle, what changes it introduces to the user interface, and the specific functionalities it makes available for pipeline developers, add-on creators, and artists wanting to test work-in-progress capabilities.

What is the Developer Extras Toggle?

Developer Extras is an interface option designed primarily for Blender developers and Python scripters, though standard users often enable it to preview upcoming tools. By default, Blender hides incomplete features and technical metadata to ensure software stability and keep the interface clean for production work. Enabling Developer Extras reveals these hidden settings without requiring a custom build from source code.

How to Enable Developer Extras

  1. Open Blender and go to the top menu bar.
  2. Select Edit > Preferences.
  3. In the left navigation menu, click on the Interface tab.
  4. Under the Display section, check the box labeled Developer Extras.

Once enabled, a new Experimental tab will immediately appear at the bottom of the left sidebar in the Preferences window, and contextual menus across the software will display technical inspection options.

Features Unlocked by Developer Extras

1. The Experimental Preferences Tab

The primary benefit for artists is the Experimental tab in Preferences. Depending on the version of Blender you are running, this tab allows you to toggle prototype features before they are officially released. Common experimental features include:

  • New Sculpting Tools and Brushes: Early iterations of brush engines and dynamic topology improvements.
  • Geometry Nodes Extensions: Unreleased nodes, experimental data types, and prototyping tools.
  • Rendering and Viewport Upgrades: Work-in-progress features for EEVEE and Cycles, such as path-guiding updates, advanced light linking, or new viewport overlays.
  • Physics and Simulation: Alternative solvers and performance optimizations for cloth, fluid, and hair systems.

Note: Features in the Experimental tab may change or cause crashes, making them unsuitable for critical production environments.

2. UI Inspection and Python Tooling

For technical artists and programmers, Developer Extras enhances right-click context menus throughout the entire interface:

  • Online Python Reference: Right-clicking any button or property provides a direct link to the relevant Blender Python API documentation page.
  • Edit Source: Opens the Python script that generates that specific UI element directly in Blender’s Text Editor.
  • View Source Code: Displays the underlying C/C++ source code location for native operators.
  • Copy Python Command: Allows you to quickly copy the exact Python data path or operator call to your clipboard for use in scripting.

3. Debugging Tools and Hidden Menus

Developer Extras unlocks additional diagnostic tools across multiple editors:

  • Advanced Search Options: The Operator Search menu exposes internal functions, such as performance benchmarks, memory cleanup utilities, and redraw timers.
  • Icon Viewer: Adds an icon browser to the Text Editor to help add-on developers choose built-in Blender icons for custom interfaces.
  • Node and Mesh Debug Overlays: Unlocks extra visual diagnostic modes in the 3D Viewport and Node Editors to inspect mesh indices, vertex weights, and execution orders.
