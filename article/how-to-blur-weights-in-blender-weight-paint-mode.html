How to Blur Weights in Blender Weight Paint Mode

Blurring weights in Blender’s Weight Paint Mode is an essential technique for creating smooth transitions between bone influences on a 3D mesh. This article covers how to use the built-in Blur brush to manually smooth specific areas, as well as how to apply the global Smooth filter across entire vertex groups for quick, clean rigging results.

Method 1: Using the Blur Brush

  1. Select your armature, hold Shift, select the mesh, and enter Weight Paint Mode (Ctrl + Tab > Weight Paint).
  2. Select the specific bone or vertex group you want to modify.
  3. Open the left Toolbar (T key) and select the Blur tool.
  4. Adjust the brush settings in the top header bar:
    • Radius: Controls brush size (F key shortcut).
    • Strength: Controls the intensity of the blur effect (Shift + F shortcut).
  5. Click and drag over the mesh regions where you want to soften hard weight transitions.

Method 2: Using the Global Smooth Tool

If you need to smooth an entire vertex group instantly without painting manually:

  1. Enter Weight Paint Mode with your mesh and target vertex group selected.
  2. Click on the Weights menu located in the top-left of the 3D Viewport header.
  3. Select Smooth from the dropdown menu.
  4. Expand the Smooth Weights operator panel in the bottom-left corner of the Viewport to adjust parameters:
    • Factor: Increases or decreases the overall strength of the blur.
    • Iterations: Multiplies how many times the smooth calculation is applied.
    • Subset: Limits the operation to active groups, selected vertices, or all groups.

Helpful Options for Better Blurring

  • Auto Normalize: Enable Auto Normalize in the Tool panel (N key > Tool tab > Options). This automatically adjusts other bone influences so the total weight value on any vertex never exceeds 1.0 while blurring.
  • Restrict to Selection: Select specific faces or vertices in Edit Mode, switch to Weight Paint Mode, and click the Vertex/Face Selection Masking icons in the top bar to restrict the blur tool strictly to those selected areas.
