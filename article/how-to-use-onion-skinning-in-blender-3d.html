How to Use Onion Skinning in Blender 3D

Onion skinning—also known as ghosting—allows animators to view transparent overlays of preceding and succeeding frames to perfect timing, spacing, and movement arcs. In Blender, onion skinning is natively integrated into the Grease Pencil system for 2D workflows, while 3D character animators utilize Motion Paths, viewport visualization techniques, or dedicated add-ons to achieve 3D mesh ghosting. This guide covers how to enable and customize these tools to visualize your animation in Blender.

Onion Skinning with Grease Pencil

If you are using Grease Pencil for roughing out 2D animation or blocking 3D scene planning:

  1. Select your Grease Pencil object in the viewport.
  2. Open the Object Data Properties tab (the green squiggle icon) in the Properties panel.
  3. Locate and expand the Onion Skinning panel, then check the box to enable it.
  4. Go to the Layers panel directly above it and ensure the onion skinning icon (the multi-layered square) is enabled for the specific layer you want to preview.
  5. In the Onion Skinning settings, adjust:
    • Frames Before / After: Set how many previous and future frames are visible.
    • Color: Assign distinct colors (typically red for past frames and green for future frames) to differentiate directions.
    • Opacity: Control the transparency fade for cleaner visibility.

Using Motion Paths for 3D Rigs (Native Ghosting Alternative)

Blender handles native 3D ghosting primarily through Motion Paths, which visually display the trajectory and frame intervals of selected bones or objects.

  1. Select your 3D character rig and switch to Pose Mode.
  2. Select the specific bones you want to track (e.g., the head, hands, or feet).
  3. Open the Armature Data Properties tab (the running person icon) or the Pose menu at the top of the 3D Viewport.
  4. Navigate to the Motion Paths section.
  5. Set the Display Range to either a custom frame range or Around Frame to track a set number of frames relative to the current playhead.
  6. Click Calculate (or Update Paths). Blender will generate a path showing the exact arc of motion, with tick marks indicating keyframe positions and spacing.

Enabling 3D Mesh Ghosting via Add-ons

Because Blender does not have a native, real-time mesh ghosting feature for standard 3D geometry out of the box, animators rely on lightweight add-ons to generate ghosted meshes:

  1. Download a 3D onion skinning add-on (popular options include Onion Skin Tools or Animation Ghost).
  2. Go to Edit > Preferences > Add-ons, click Install, and select the downloaded file.
  3. Check the box to activate the add-on.
  4. In the 3D Viewport, open the sidebar (N key) and locate the add-on tab.
  5. Select your animated mesh or rig, set the number of ghost frames, and click Generate Ghosts to display transparent snapshots of your 3D mesh across the timeline.
