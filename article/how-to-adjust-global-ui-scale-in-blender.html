How to Adjust Global UI Scale in Blender

Adjusting the global user interface (UI) scale in Blender allows you to resize text, icons, and buttons across the entire application to better fit high-resolution (4K) displays or improve readability. This guide provides clear, step-by-step instructions on how to find and modify the Resolution Scale setting within Blender's preferences, as well as how to adjust display scale for individual windows.

Steps to Change the Global UI Scale

  1. Open Preferences:
    Launch Blender and click on Edit in the top menu bar, then select Preferences. Alternatively, use the keyboard shortcut Ctrl + , (Windows/Linux) or Cmd + , (macOS).

  2. Navigate to the Interface Tab:
    In the Preferences window, select Interface from the left-hand navigation sidebar.

  3. Locate Resolution Scale:
    Under the Display category near the top of the window, locate the Resolution Scale slider.

  4. Adjust the Scale Value:

    • Increase the UI size: Drag the slider to the right or enter a value higher than 1.00 (e.g., 1.25 or 1.50 for high-density monitors).
    • Decrease the UI size: Drag the slider to the left or enter a value lower than 1.00 (e.g., 0.85).

  5. Save Preferences:
    Blender automatically saves preferences by default. If auto-save is disabled, click the Preferences menu icon (three horizontal lines) in the bottom-left corner of the Preferences window and click Save Preferences.

Alternative: Scaling Specific Windows

If you only need to resize specific panels or editors without altering the entire global UI:

  • Position your mouse cursor over the editor window you wish to scale.
  • Hold Ctrl and press Middle Mouse Button Drag up or down, or press Numpad + and Numpad - to zoom the UI element size in that specific window.
