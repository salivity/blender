How to Use the Clone Brush in Blender Texture Paint

The Clone Brush in Blender’s Texture Paint mode is a powerful tool used to copy texture detail from one region of an image or 3D model and paint it onto another area. It is primarily utilized by 3D artists to fix visible UV seams, duplicate complex texture patterns, cover up flaws, and seamlessly blend surface details across a 3D mesh. By sampling pixels from a designated source, the brush allows for precise texture cloning without needing to redraw details manually.

Primary Uses of the Clone Brush

  • Hiding UV Seams: When texturing complex 3D models, UV seams often create noticeable lines where different parts of the texture map meet. The Clone Brush allows you to paint across these boundaries, copying texture data from adjacent faces to smooth out and hide the seam entirely.
  • Duplicating Surface Details: If a texture features specific high-detail elements—such as rivets, scars, fabric weaves, or rust spots—you can use the Clone Brush to duplicate those exact features across different areas of the model quickly.
  • Cleaning Up Textures: The tool works exceptionally well for removing unwanted artifacts, noise, or mistakes on a texture map by cloning a clean, clear section of the surface over the damaged area.
  • Projecting 3D Views: In advanced workflows, the Clone Brush can sample from a secondary image texture or a 3D camera projection source, allowing artists to project photo references directly onto specific parts of their 3D object.

How the Clone Brush Functions

The Clone Brush relies on a reference source to determine what pixels to copy. Blender offers two main methods for setting up this source:

  1. 3D Cursor Source: By default, the Clone Brush can use the 3D Cursor as its sampling anchor point. You place the 3D Cursor over the area you wish to copy, and as you paint elsewhere on the mesh, the brush copies the offset pixels relative to that cursor position.
  2. Secondary Image Texture Source: In the brush tool settings, you can toggle the clone source to “Image” and select a secondary texture file. Painting with the Clone Brush will then paint the pixels of that external image directly onto your target 3D model’s texture map.

By controlling the brush strength, radius, and falloff settings, artists can smoothly blend copied pixels into existing textures, making the Clone Brush an essential tool for professional 3D texturing workflows in Blender.
