How to Use the Normal Map Node in Blender

The Normal Map node in Blender allows you to add fine surface details—such as bumps, scratches, and textures—to a 3D model without increasing its polygon count. This guide provides a straightforward walk-through on how to set up the Normal Map node in the Shader Editor, correctly configure texture settings, and plug it into your material workflow for optimal visual results.

Step 1: Open the Shader Editor

Select the object you want to apply the material to, then switch your workspace layout to the Shading tab or change any window panel to the Shader Editor. Ensure your object has an active material assigned.

Step 2: Add Your Texture Map

  1. Press Shift + A inside the Shader Editor.
  2. Go to Texture > Image Texture and click to place the node.
  3. Click Open on the node and select your normal map image file (typically a blue/purple-tinted image).

Step 3: Set Color Space to Non-Color

This is a critical step to ensure Blender treats the image as vector data rather than color information: 1. On the Image Texture node, click the Color Space dropdown menu (set to sRGB by default). 2. Select Non-Color.

Step 4: Add the Normal Map Node

  1. Press Shift + A in the Shader Editor.
  2. Go to Vector > Normal Map and place the node between the Image Texture node and your main shader node (like the Principled BSDF).

Step 5: Connect the Nodes

Wire the nodes together in the following sequence: * Connect the Color output of the Image Texture node to the Color input of the Normal Map node. * Connect the Normal output of the Normal Map node to the Normal input of the Principled BSDF node.

Key Node Settings

  • Strength: Controls the depth intensity of the effect. The default value is 1.0. Lower the value for subtle details or raise it to exaggerate the lighting bumps.
  • Space: Leave this set to Tangent Space for standard UV-unwrapped models. Use Object Space or World Space only if your normal map was explicitly baked in those spaces.
  • UV Map: If your 3D mesh uses multiple UV maps, click this field to specify which UV layout the normal map should align with.
