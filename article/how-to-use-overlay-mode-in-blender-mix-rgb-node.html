How to Use Overlay Mode in Blender Mix RGB Node

The Overlay blend mode in Blender's Mix RGB node combines the Multiply and Screen blend modes to enhance contrast and blend colors without washing out extreme light or dark areas. This guide explains how the Overlay blend mode works mathematically, how to set it up in the Shader Editor or Compositor, and the best practical use cases for texturing and compositing.

Understanding How Overlay Blend Mode Works

Overlay calculates the brightness of the base color (Color 1) to determine which blend mode to apply:

  • Dark Areas (Base color brightness < 0.5): Uses the Multiply mode. This deepens shadows and darkens midtones.
  • Light Areas (Base color brightness > 0.5): Uses the Screen mode. This brightens highlights and creates soft glows.
  • Neutral Grey (Base color brightness = 0.5): Leaves the underlying color unchanged.

Because midtones shift toward the overlay color (Color 2) while highlights and shadows retain their structure, Overlay is ideal for adding surface detail, procedural noise, and stylized color grading.

How to Set Up Overlay in the Mix RGB Node

(Note: In Blender 3.4 and newer, the Mix RGB node is named Mix Color with the data type set to RGB.)

  1. Open the Editor: Switch to either the Shader Editor (for material nodes) or the Compositor (for post-processing).
  2. Add the Mix Node: Press Shift + A, go to Color > Mix Color (or Mix RGB in older versions), and place it in your node setup.
  3. Change the Mode to Overlay: Click the dropdown menu at the top of the node (which defaults to Mix) and select Overlay.
  4. Connect Input 1 (Base Layer): Plug your main texture, base color, or render output into the top color input slot (Color1 / A).
  5. Connect Input 2 (Overlay Layer): Plug the texture, color tint, or procedural noise pattern into the second color input slot (Color2 / B).
  6. Adjust the Factor: Use the Factor (Fac) slider to control the strength of the overlay effect. A value of 0.0 shows only the base layer, 1.0 applies the full Overlay effect, and 0.5 offers a balanced blend.

Common Use Cases

  • Adding Surface Scratches and Dirt: Overlay subtle surface imperfections onto a base color material without destroying the base material's original light-and-dark values.
  • Ambient Occlusion (AO) Overlay: Combine a baked AO map with a base diffuse texture to deepen crevice shadows while preserving highlighted edges.
  • Stylized Lighting and Color Grading: Blend color gradients over a rendered image in the Compositor to shift the mood of a scene without flattening the image contrast.
