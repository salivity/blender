How to Adjust Camera Sensor Size and Clipping in Blender

Adjusting the camera sensor size and clipping limits in Blender is essential for matching real-world camera optics, managing your scene's composition, and eliminating visual glitches like z-fighting or disappearing geometry. This guide provides a straightforward walkthrough on where to find and how to configure the Sensor Size, Clip Start, and Clip End settings for your scene cameras.

Accessing Camera Properties

Before altering any settings, you must select the camera in your scene:

  1. Click on the camera in the 3D Viewport or select it from the Outliner.
  2. Navigate to the Properties Panel (usually on the right side of the interface).
  3. Click on the green Data Properties tab (icon looks like a movie camera).

Adjusting Camera Sensor Size

The sensor size determines the simulated physical dimensions of the camera sensor (in millimeters), which directly affects the camera's field of view in relation to its focal length.

  1. In the Object Data Properties tab, expand the Camera sub-panel.
  2. Locate the Sensor Fit option. You can set it to Auto, Horizontal, or Vertical.
  3. Enter your desired values in the Width and Height fields:
    • Sensor Width: Adjusts the horizontal dimension (default is 36 mm, standard full-frame).
    • Sensor Height: Adjusts the vertical dimension (default is 24 mm).
  4. Alternatively, choose from preset sensor sizes (such as Super 35, Micro Four Thirds, or Full Frame) using the presets menu located right above the sensor properties.

Adjusting Clip Start and Clip End

Clipping boundaries define the minimum and maximum distances from the camera within which objects are rendered. Anything closer than Clip Start or farther than Clip End will be cut off from view.

  1. In the Object Data Properties tab, expand the Lens sub-panel.
  2. Locate the Clip Start and Clip End numeric fields.
  3. Adjust the values based on your scene requirements:
    • Clip Start: Sets the closest distance an object can be to the camera before being clipped. Default is 0.1 m (10 cm). Lower this value if close-up objects are disappearing, but avoid setting it excessively low (e.g., 0.0001 m) to prevent depth buffer precision issues.
    • Clip End: Sets the maximum distance visible to the camera. Default is 100 m. Increase this value (e.g., 1000 m or higher) if distant landscape elements or large environments are being cut off.

Note on Viewport vs. Camera Clipping

The settings under the Camera Data tab strictly apply to the selected camera object and your final render. If you experience clipping while navigating the 3D Viewport outside of the camera view:

  1. Press N to open the right-side sidebar in the 3D Viewport.
  2. Select the View tab.
  3. Adjust the Clip Start and Clip End values under the View section to change the interactive viewport navigation clipping.
