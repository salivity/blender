How to Invert Colors with Nodes in Blender

Inverting colors in Blender is a simple process that allows you to swap color values or flip grayscale masks within the Shader Editor or Compositor. By using the dedicated Invert Color node, you can easily alter textures, invert roughness maps, or create unique visual effects. This guide explains how to locate, connect, and configure the Invert node step-by-step to flip color and scalar data in your Blender materials.

How to Add and Use the Invert Node

To invert any color or texture in Blender’s Shader Editor or Compositor, follow these steps:

  1. Open the Shader Editor (or Compositor) and select the material you want to edit.
  2. Press Shift + A to open the Add menu.
  3. Go to Color > Invert Color (or press S and type “Invert” into the search bar).
  4. Click to place the Invert node on your node graph.
  5. Drag the output wire from your source node (such as an Image Texture or Noise Texture) into the Color input socket of the Invert node.
  6. Connect the Color output socket of the Invert node to your destination node (such as the Base Color, Roughness, or Emission input of a Principled BSDF).

Understanding Invert Node Settings

The Invert node features two simple control settings:

  • Fac (Factor): Controls the intensity of the inversion effect. A value of 1.0 fully inverts the color values, a value of 0.0 leaves the original input unchanged, and a value of 0.5 yields a neutral gray blend.
  • Color: The input socket where you plug in the image, procedural texture, or color value you wish to invert.

Alternative Methods to Invert Colors

While the Invert Color node is the most direct solution, you can also invert values using these alternative nodes:

  • RGB Curves Node: Go to Add > Color > RGB Curves. Drag the bottom-left point of the curve to the top, and the top-right point to the bottom to invert the color channels.
  • Math Node (For Grayscale/Black and White Masks): Go to Add > Converter > Math. Set the operation to Subtract. Set the top input value to 1.0 and plug your mask into the bottom input value. This performs a 1.0 - Value calculation, flipping values between 0 and 1.
