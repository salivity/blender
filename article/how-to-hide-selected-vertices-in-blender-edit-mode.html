How to Hide Selected Vertices in Blender Edit Mode

Hiding selected vertices in Blender’s Edit Mode is an essential technique for decluttering your viewport and focusing on specific parts of a 3D model. This guide covers the quick keyboard shortcuts and menu options used to hide selected vertices, hide unselected geometry, and reveal hidden vertices whenever you need them back.

How to Hide Selected Vertices

  1. Press Tab to enter Edit Mode on your mesh object.
  2. Ensure you are in Vertex Select Mode (press 1 on your top number row).
  3. Select the vertices you want to hide by left-clicking, box-selecting (B), or circle-selecting (C).
  4. Press H on your keyboard.

The selected vertices, along with any connected edges and faces, will instantly disappear from the view.

Useful Hiding Shortcuts in Edit Mode

  • Hide Selected (H): Hides all currently selected vertices.
  • Hide Unselected (Shift + H): Hides everything except the currently selected vertices. This is ideal for isolating a specific area of your mesh.
  • Unhide All (Alt + H): Reveals all hidden vertices, edges, and faces in the active object.

Hiding Vertices Using the Top Menu

If you prefer using the user interface instead of keyboard shortcuts:

  1. Select your target vertices in Edit Mode.
  2. Click on Mesh in the top-left corner of the 3D Viewport.
  3. Hover over Hide.
  4. Choose Hide Selected, Hide Unselected, or Reveal Hidden.
