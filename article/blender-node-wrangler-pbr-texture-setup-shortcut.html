Blender Node Wrangler PBR Texture Setup Shortcut

Setting up Physically Based Rendering (PBR) texture sets manually in Blender can be tedious and time-consuming. By enabling Blender's built-in Node Wrangler add-on, you can automatically import, map, and connect an entire set of PBR textures—including Base Color, Roughness, Metallic, Normal, and Displacement maps—directly to a Principled BSDF shader using a single keyboard shortcut: Ctrl + Shift + T.

How to Enable Node Wrangler

Before using the shortcut, ensure the Node Wrangler add-on is active:

  1. Go to Edit > Preferences.
  2. Select the Add-ons tab on the left.
  3. Search for Node Wrangler in the search bar.
  4. Check the box next to Node: Node Wrangler to enable it.
  5. Close the Preferences window.

How to Use the PBR Texture Setup Shortcut

Once Node Wrangler is enabled, follow these steps to import your PBR texture set automatically:

  1. Open the Shader Editor window.
  2. Ensure you have a material assigned to your object and click on the Principled BSDF node to select it (it will highlight in white or orange).
  3. Press Ctrl + Shift + T on your keyboard.
  4. In the file browser window that appears, navigate to your texture folder.
  5. Select all the texture files that belong to the PBR set (hold Shift or Ctrl to select multiple images).
  6. Click the Principled Texture Setup button in the bottom right corner.

How It Works Behind the Scenes

Node Wrangler reads standard file naming conventions (such as _BaseColor, _Roughness, _Metallic, _Normal, _Displacement, _AO, or _Height) and automatically performs the following tasks:

  • Creates individual Image Texture nodes for each file.
  • Connects each map to its corresponding input slot on the Principled BSDF.
  • Sets appropriate color spaces automatically (e.g., sRGB for Base Color, and Non-Color for Roughness, Metallic, and Normal maps).
  • Adds and connects a Normal Map node for normal textures.
  • Adds a Texture Coordinate and Mapping node connected to all textures for easy UV scaling and rotation.
