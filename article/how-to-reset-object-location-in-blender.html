How to Reset Object Location in Blender

Resetting an object's location in Blender is a fundamental skill that allows you to instantly move any selected mesh or element back to the center of the 3D world space (0, 0, 0). Whether you need to re-center a misplaced object or prepare a model for animation, Blender provides quick keyboard shortcuts and menu options to clear transforms effortlessly. This guide outlines the most direct methods to reset location, along with related transform resets.

Method 1: The Keyboard Shortcut (Fastest)

  1. Left-click to select the object in the 3D Viewport.
  2. Press Alt + G on your keyboard.

This command clears the location offset and immediately moves the object's origin point to the world coordinates (0, 0, 0).

Method 2: Using the Object Menu

  1. Select the target object.
  2. Click Object in the top-left menu bar of the 3D Viewport.
  3. Hover over Clear.
  4. Click Location.

Method 3: The Sidebar (N-Panel)

  1. Select your object.
  2. Press N to toggle the Sidebar on the right side of the 3D Viewport.
  3. Click the Item tab.
  4. Under the Transform section, manually type 0 into the X, Y, and Z Location fields.

Resetting Rotation and Scale

If you also need to reset other transforms alongside the location, use these standard shortcuts:

  • Reset Rotation: Select object and press Alt + R
  • Reset Scale: Select object and press Alt + S
  • Reset All: Press Alt + G, Alt + R, and Alt + S in sequence.

Troubleshooting: Object Does Not Move to Center

If pressing Alt + G sets the Location values to 0 but the mesh remains off-center, the object's origin point is not aligned with its geometry.

To fix this:

  1. Select the object.
  2. Right-click in the viewport and go to Set Origin.
  3. Choose Origin to Geometry to move the origin back to the center of the mesh, or Geometry to Origin to snap the mesh directly to the origin point.
