Blender UV Project Modifier Camera Projection Guide

The UV Project modifier in Blender is a non-destructive tool that generates or overrides an object's UV coordinates by projecting them from the perspective of an external object, such as a camera. This article explains what the modifier does, how perspective camera projection works, and how to set it up step-by-step for techniques like matte painting and visual effects camera mapping.

What is the UV Project Modifier?

The UV Project modifier acts like a real-world slide projector. Instead of manually unwrapping a 3D mesh and fixing seams, this modifier casts UV coordinates onto the mesh surface from the position, rotation, and field of view of one or more specified "Projector" objects. Because it is a modifier, the projection is dynamic; moving the projector or the geometry updates the texture coordinates in real time without altering the base mesh data until the modifier is applied.

How It Projects Textures from a Camera Perspective

When a camera is assigned as the projector, Blender calculates the UV coordinates using the camera's view frustum. Rays are effectively cast from the camera's focal point across its field of view toward the geometry. The resulting UV coordinates map the pixels of an image directly onto the visible faces of the mesh relative to that camera's viewpoint.

This process ensures that any image rendered from that exact camera angle aligns with the 3D surface geometry, creating a seamless match between 2D reference imagery and 3D scenes.

Step-by-Step Setup

  1. Prepare the Mesh and UV Map: Select your target 3D object. In the Object Data Properties tab (green triangle icon), expand the UV Maps panel and ensure a UV Map exists (create one if necessary).
  2. Assign the Material: Create a material for the object. Add an Image Texture node containing the image you want to project, and connect its vector input to an UV Map node set to your target UV map.
  3. Set Up the Projector Camera: Add a Camera to your scene (or select an existing one) and align it to the exact view angle and focal length from which you want to project the image.
  4. Add the Modifier: Select your mesh, open the Modifier Properties tab (wrench icon), and add the UV Project modifier.
  5. Configure the Modifier Properties:
    • UV Map: Select the UV map designated in your material.
    • Projectors: Set the number of projectors to 1 (or more if blending multiple angles) and assign your projection Camera in the object slot.
    • Aspect Ratio: Enter the horizontal (X) and vertical (Y) aspect ratio or pixel dimensions matching your source image (e.g., 1920 for X and 1080 for Y) to prevent image stretching.
    • Scale: Adjust scale parameters if you need to fit or fill the projection area without altering camera settings.

Common Use Cases

  • Camera Projection and Matte Painting: Mapping 2D concept art or live-action background plates onto simple 3D geometry to enable realistic parallax with a moving render camera.
  • Decal Placement: Casting logos, dirt, or labels onto complex, curved surfaces without altering existing UV layouts.
  • Rapid Prototyping: Applying reference textures to rough blockouts without manual UV unwrapping.
