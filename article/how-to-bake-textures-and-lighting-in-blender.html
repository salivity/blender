How to Bake Textures and Lighting in Blender

Baking lighting and procedural materials into static UV texture maps in Blender allows you to optimize complex visual assets for real-time rendering in Unity or Unreal Engine. This process converts procedural node setups, complex lighting interactions, shadows, and ambient occlusion into standard image maps (such as Albedo, Normal, or Combined maps). By using the Cycles render engine and properly unwrapped UVs, you can bake high-fidelity visuals into lightweight assets ready for game engine import.

1. Prepare Model UVs

Before baking, your 3D mesh must have a non-overlapping UV map.

  1. Select your object in Blender and switch to Edit Mode (Tab).
  2. Open the UV Editor alongside the 3D Viewport.
  3. Select all faces (A), press U, and select Smart UV Project or manually unwrap the mesh using marked seams.
  4. Ensure no UV islands overlap, and give them adequate margin (e.g., 0.01 to 0.02) to prevent texture bleeding.

2. Create the Target Texture Node

Blender requires a designated image node to store the baked data.

  1. Switch to the Shading workspace.
  2. In the Shader Editor, ensure the material you want to bake is active.
  3. Press Shift + A, go to Texture, and select Image Texture.
  4. Click New on the node.
  5. Name the texture (e.g., T_MeshName_Baked), set the desired resolution (typically 2048x2048 or 4096x4096), and uncheck 32-bit Float unless working with HDR maps.
  6. Keep this Image Texture node selected (active), but do not connect its output to anything.
  7. If your object uses multiple materials, copy and paste this identical Image Texture node into every material slot on the object, keeping it selected in each.

3. Configure the Bake Settings

Baking is only supported natively through the Cycles render engine.

  1. Go to the Render Properties tab in the Properties panel.
  2. Set the Render Engine to Cycles (switch Device to GPU Compute if available).
  3. Under the Sampling section, adjust the Render Samples (32 to 128 samples is usually sufficient for baking).
  4. Scroll down and expand the Bake section.
  5. Choose your Bake Type:
    • Combined: Bakes all material properties, direct lighting, indirect lighting, and shadows into a single map (ideal for mobile or unlit shaders in Unity/Unreal).
    • Diffuse: Bakes base color. Under Contributions, disable Direct and Indirect if you only want an unlit Albedo/Base Color texture.
    • Roughness / Normal / Ambient Occlusion: Use these individual passes if you are assembling a full PBR material set.
  6. Set the Margin (padding) between 4px and 16px to prevent black edges around UV borders.

4. Execute the Bake

  1. Ensure your target mesh is selected in the 3D Viewport.
  2. Ensure the target Image Texture node is active/highlighted in the Shader Editor.
  3. In the Render Properties under Bake, click the Bake button.
  4. Monitor the progress bar at the bottom of the Blender interface.

5. Save the Baked Image

Blender does not automatically save baked textures to disk.

  1. Switch to the Image Editor.
  2. Select your baked texture from the image dropdown list.
  3. Go to Image > Save As... in the top menu.
  4. Choose a file format like PNG (16-bit for normal/displacement, 8-bit for color) or TGA, and save it to your project folder.

6. Import into Unity or Unreal Engine

Unity

  1. Drag the exported image and your 3D model (.fbx or .obj) into the Unity Project panel.
  2. Create a new Material using the Standard or Universal Render Pipeline (URP) Lit shader.
  3. Assign the baked texture to the Base Map / Albedo slot. If you baked a Combined map with lighting, you can use an Unlit/Texture shader to maximize performance.

Unreal Engine

  1. Import your mesh and baked texture into the Content Browser.
  2. Open your texture settings: if baking normal maps or data masks (like roughness), uncheck sRGB. For color/combined maps, leave sRGB checked.
  3. Create a Material, drag the texture into the Material Graph, and connect the RGB output to Base Color (or Emissive Color if using pre-baked lighting on an Unlit material).
