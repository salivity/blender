How to Find System Preferences in Blender

Finding the system preferences in Blender is a straightforward process that allows you to customize your graphics hardware settings, memory limits, audio output, and interface options. This guide explains how to locate the Preferences window, navigate directly to the System tab, and use shortcut keys to access these settings quickly on Windows, macOS, and Linux.

How to Open the Preferences Menu

You can access Blender's Preferences through the main menu bar at the top of the screen:

  1. Click on Edit in the top-left corner of the Blender interface.
  2. Select Preferences... at the bottom of the drop-down menu.

Note for macOS users: You can also click Blender in the top menu bar and select Preferences....

Keyboard Shortcuts

To open the Preferences window instantly, use the following key combinations:

  • Windows / Linux: Press Ctrl + , (Comma)
  • macOS: Press Cmd + , (Comma)

Alternatively, press F3 to open the search menu, type Preferences, and press Enter.

Locating the System Tab

Once the Preferences window is open:

  1. Look at the vertical navigation menu on the left side of the window.
  2. Scroll down and click on the System tab.

Key Settings Inside the System Tab

The System tab controls hardware-level configurations and performance options, including:

  • Cycles Render Devices: Configure your GPU acceleration (CUDA, OptiX, HIP, OneAPI, or Metal) for faster rendering.
  • Memory & Limits: Adjust the maximum number of Undo Steps and memory limits for video editing and caching.
  • Sound: Select your preferred audio output device, sample rate, and mixing buffers.
  • Operating System Settings: Manage graphics tablet API preferences and desktop integration options.

Saving Your Preferences

By default, Blender automatically saves changes made in the Preferences window. If auto-save is disabled, click the three lines (hamburger menu) icon in the bottom-left corner of the Preferences window and select Save Preferences.
