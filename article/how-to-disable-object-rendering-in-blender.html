How to Disable Object Rendering in Blender

Disabling an object from rendering in Blender allows you to keep items visible in your viewport for reference or editing without including them in your final image or animation. This process can be accomplished quickly by enabling the render restriction toggle in the Outliner, adjusting settings in the Object Properties panel, or disabling entire collections at once.

Method 1: Using the Outliner (Recommended)

By default, Blender hides the camera toggle icon in the Outliner. To make it visible and disable your object from rendering, follow these steps:

  1. Look at the Outliner panel in the top-right corner of the interface.
  2. Click the Filter icon (a funnel shape) at the top right of the Outliner menu.
  3. Under the Restriction Toggles section, click the Disable in Renders icon (the small camera icon) to activate it.
  4. Locate your object in the Outliner list.
  5. Click the Camera icon next to your object’s name. If the icon turns grey or disappears (depending on your Blender theme), the object will no longer appear in final renders.

Method 2: Using the Object Properties Panel

If you prefer using the sidebar menus, you can control an individual object's visibility settings directly from the Object Properties panel:

  1. Select the object in your 3D Viewport or Outliner.
  2. Go to the Properties panel on the right side of the screen.
  3. Click on the Object Properties tab (represented by an orange square icon).
  4. Scroll down and expand the Visibility dropdown menu.
  5. Uncheck the Render checkbox.

Method 3: Disabling an Entire Collection from Render

If you have multiple objects grouped inside a collection that you want to exclude from the final output:

  1. Find the Collection in the Outliner.
  2. Ensure the Disable in Renders toggle (camera icon) is enabled via the Outliner's Filter menu.
  3. Click the Camera icon next to the Collection name to disable render visibility for every object contained within that collection.

Important Note: Viewport Hide vs. Render Hide

Pressing H on your keyboard hides an object from the 3D Viewport, but it will still appear in the final render. To quickly sync viewport visibility with render visibility, use the Outliner toggles: the Eye icon controls Viewport visibility, while the Camera icon controls Render visibility.
