How to Restrict Transformation to a Single Axis in Blender

Restricting transformations to a single axis in Blender allows you to move, rotate, or scale objects and mesh elements along a precise 3D path. Whether you are using hotkeys, mouse gestures, or the user interface, locking your actions to the X, Y, or Z axis prevents unwanted movement and ensures accurate modeling. This guide explains the primary methods to lock transformations to a single axis quickly.

Method 1: Use Keyboard Shortcuts (Fastest Method)

The standard and most efficient way to restrict movement in Blender is using hotkeys.

  1. Select the object or element you want to modify.
  2. Press the key for the desired transformation:
    • G to Move (Grab)
    • R to Rotate
    • S to Scale
  3. Immediately press the key corresponding to the axis you want to lock to:
    • X for the Global X-axis (Red line)
    • Y for the Global Y-axis (Green line)
    • Z for the Global Z-axis (Blue line)
  4. Move your mouse or type a specific numerical value, then press Enter or Left-Click to confirm.

Tip: Pressing the axis key a second time (e.g., G -> X -> X) locks the transformation to the object's Local Axis instead of the Global Axis.

Method 2: Middle Mouse Button Snapping

If you prefer using the mouse over keyboard shortcuts:

  1. Initiate the transformation by pressing G, R, or S.
  2. Click and hold the Middle Mouse Button (MMB) while moving the cursor slightly toward the desired axis.
  3. Blender will display a colored line indicating the locked axis.
  4. Release the Middle Mouse Button and complete the movement, then Left-Click to confirm.

Method 3: Exclude an Axis (Plane Locking)

If you want to move an object freely on two axes while locking out a third (for example, moving an object along a floor without changing its height):

  1. Press G, R, or S.
  2. Press Shift + [Axis Key] to exclude that specific axis:
    • Shift + Z: Moves along X and Y axes, excluding height (Z).
    • Shift + X: Moves along Y and Z axes.
    • Shift + Y: Moves along X and Z axes.

Method 4: Lock Axes in the Properties Sidebar

To permanently prevent an object from moving, rotating, or scaling along specific axes:

  1. Press N to open the Sidebar in the 3D Viewport.
  2. Go to the Item tab.
  3. Find the Transform section (Location, Rotation, or Scale).
  4. Click the Padlock icon next to any axis field (X, Y, or Z) to lock it. Once locked, the object cannot be transformed along that axis until unlocked.
