How to Transfer UV Maps Between Meshes in Blender

Transferring UV maps between identical meshes in Blender is a fast way to copy texture coordinates from one object to another without re-unwrapping. Whether you are working with duplicated geometry, backup files, or modular assets, Blender allows you to copy UV data instantly using the Link/Transfer Data tool or the Data Transfer modifier.

Method 1: The Quick Shortcut (Ctrl + L)

This is the fastest method when both meshes have identical topology and vertex counts.

  1. Select Target First: Left-click to select the object (or multiple objects) that needs the new UV map.
  2. Select Source Last: Hold Shift and left-click the mesh that already has the correct UV map. It must be the active selection (highlighted in a lighter orange outline).
  3. Open the Link Menu: Press Ctrl + L on your keyboard.
  4. Copy UV Maps: Click Copy UV Maps from the pop-up menu.

The UV layout from the active object will instantly overwrite or add to the UV maps of the target objects.

Method 2: The Data Transfer Modifier

Use this method if you want a non-destructive workflow or if the meshes have slight differences in vertex order.

  1. Select Target Mesh: Select the object that is missing the UV map.
  2. Add Modifier: Go to the Modifier Properties tab (wrench icon) and add a Data Transfer modifier.
  3. Set Source: In the Source field, select the object containing the correct UV map.
  4. Enable Face Corner Data: Check the Face Corner Data box to expand its options.
  5. Select UVs: Click the UVs button.
  6. Choose Mapping Mode:
    • Choose Topology if the vertex indices match completely.
    • Choose Nearest Face Interpolated or Nearest Corner of Nearest Face if the topology differs slightly.
  7. Apply Modifier: Click the dropdown menu on the modifier header and select Apply (or press Ctrl + A while hovering over the modifier).

Troubleshooting UV Transfers

  • Mismatched Maps: Ensure both objects have UV map channels named identically in the Object Data Properties tab under the UV Maps section.
  • Distorted UVs: If the transferred UVs appear stretched, apply object transformations on both models by selecting them and pressing Ctrl + A > All Transforms before transferring.
