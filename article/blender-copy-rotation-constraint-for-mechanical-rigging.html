Blender Copy Rotation Constraint for Mechanical Rigging

The Copy Rotation constraint in Blender is an essential tool for mechanical rigging, allowing one object or bone to mirror the rotational movement of another automatically. This guide covers how to apply the Copy Rotation constraint, configure its axis and space settings for mechanical setups like gears and hinges, and optimize your workflow for precise automated motion.

Step 1: Set Up Your Objects or Bones

Mechanical rigging typically involves Armatures (bones) or Mesh Objects. Before applying constraints, ensure your control object (the Target) and driven object (the Owner) are correctly positioned.

  1. Set pivot points precisely at the rotational axes of your mechanical parts.
  2. If using separate mesh objects, apply their rotations by pressing Ctrl + A and selecting Rotation.
  3. If using an Armature, ensure the target bone and owner bone are oriented correctly in Edit Mode.

Step 2: Apply the Copy Rotation Constraint

  1. Select the Owner object or bone (the part you want to be driven).
  2. Open the Object Constraint Properties tab (or Bone Constraint Properties if working inside an armature).
  3. Click Add Object Constraint (or Add Bone Constraint).
  4. Select Copy Rotation from the Transform column.
  5. In the Target field, select your driving object or armature.
  6. If the target is an armature, select the specific target bone in the Bone field that appears.

Step 3: Configure Settings for Mechanical Motion

To achieve accurate mechanical behavior, adjust the constraint’s properties:

  • Axis Controls (X, Y, Z): Enable only the axes required for the motion. For example, a single-axis hinge only needs one active rotation axis (e.g., the Z-axis).
  • Invert Toggle: Check the Invert box next to an active axis if the driven object must rotate in the opposite direction of the target. This is useful for counter-rotating parts like meshing gears.
  • Target and Owner Space: Change both Target and Owner space drop-downs from World Space to Local Space. This ensures the rotation works relative to the local orientation of the parts, preventing unwanted twisting when the entire rig moves.
  • Mix Mode: Set how the constrained rotation blends with existing transform data:
    • Replace: Completely overrides the owner’s rotational transform.
    • Add / Before Original / After Original: Allows you to retain manual rotation on the owner while still inheriting motion from the target.
  • Influence: Keep at 1.0 for rigid mechanical locking, or lower the value to create proportional movement.

Common Mechanical Use Cases

Interlocking Gears

Assign a Copy Rotation constraint to Gear B targeting Gear A. Limit the active constraint to the rotational axis (e.g., Z), enable Invert for that axis, and set both Target and Owner spaces to Local Space. Rotating Gear A will turn Gear B in the opposite direction automatically.

Mechanical Linkages and Levers

For parallel arms or support struts, set secondary arms to copy the rotation of a primary control lever. Setting the target and owner spaces to Local Space keeps all arms synchronized regardless of how the root vehicle or machine moves through the scene.

Troubleshooting Alignment Issues

  • Object Spins Out of Alignment: If the owner snaps to an incorrect rotation upon applying the constraint, verify that both target and owner objects have applied rotations (Ctrl + A > Rotation).
  • Unwanted Flipping: Double-check that both Target and Owner spaces are set consistently (usually Local Space for mechanical rigs).
  • Axes Don’t Match: Turn on Axes in the Viewport Display settings for your objects or bones to ensure the local X, Y, and Z axes point in the same relative directions.
