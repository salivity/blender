How to Use the Hue Saturation Value Node in Blender

The Hue Saturation Value (HSV) node in Blender is a fundamental color manipulation tool used in both the Shader Editor and the Compositor. It allows artists to non-destructively adjust the color tone, intensity, and brightness of textures, materials, or rendered images by converting standard RGB data into HSV components. This guide explains how to add the node, understand its controls, and apply it efficiently in your 3D workflow.

Adding the HSV Node

  1. Open the Shader Editor or Compositor workspace.
  2. Ensure Use Nodes is checked at the top of the editor.
  3. Press Shift + A (or click Add in the top menu).
  4. Navigate to Color > Hue Saturation Value.
  5. Place the node between your input source (such as an Image Texture node) and your output node (such as the Principled BSDF).

Understanding the Node Inputs and Settings

The HSV node processes color data through four primary sliders:

  • Hue (Default: 0.5): Controls the color tint along the color wheel.
    • Setting the value to 0.5 maintains the original color.
    • Adjusting above 0.5 shifts the color in one direction (towards blues and purples).
    • Adjusting below 0.5 shifts the color in the opposite direction (towards greens and yellows).
  • Saturation (Default: 1.0): Controls the vibrancy or intensity of the color.
    • A value of 0.0 completely removes all color, converting the image to grayscale.
    • A value of 1.0 preserves the original saturation level.
    • Values above 1.0 increase color intensity for a more vivid effect.
  • Value (Default: 1.0): Controls the overall brightness of the color.
    • A value of 0.0 turns the input completely black.
    • A value of 1.0 leaves the light intensity at its original level.
    • Values above 1.0 increase the brightness beyond the original exposure.
  • Fac / Factor (Default: 1.0): Controls the influence of the node on the original input image.
    • 0.0 outputs the original unmodified color.
    • 1.0 applies the full strength of the HSV adjustments.

Practical Applications in Blender

1. Creating Color Variations of Textures

Instead of importing multiple variations of the same texture, connect a single Image Texture node to an HSV node. Duplicate the material, adjust the Hue slider on the second material, and you immediately have a secondary color variant (e.g., changing green foliage to autumn red).

2. Generating Roughness or Bump Maps

To quickly generate a roughness map from a diffuse texture, connect the image color output to an HSV node. Set Saturation to 0.0 to turn the image into grayscale, and adjust Value to control the contrast and intensity of the glossiness.

3. Color Grading in the Compositor

In the Compositor, insert the HSV node between the Render Layers node and the Composite node. Use slight tweaks to Saturation and Value to perform final color balancing before exporting your rendered image or animation.
