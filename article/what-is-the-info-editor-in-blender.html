What is the Info Editor in Blender?

The Info Editor in Blender serves as the application's operation log and system reporting hub. It displays feedback on user actions, reports warnings and errors, shows Python code generated by the interface, and provides access to essential system messages. By tracking everything that happens behind the scenes, the Info Editor allows users to monitor scene performance, troubleshoot issues, and learn how to automate tasks using Python scripts.

Primary Functions of the Info Editor

The Info Editor plays a vital role in both general workflow management and technical troubleshooting in Blender.

1. Action Logging and Python Scripting

Every time you perform an action in Blender—such as moving an object, applying a modifier, or changing a material setting—Blender executes a Python command in the background. The Info Editor records these commands in real time.

This feature is invaluable for technical artists and developers because it allows you to:

  • Copy executed actions directly from the log to use in custom Python scripts or add-ons.
  • Understand how Blender's API handles specific tools and operations.
  • Automate repetitive tasks by reviewing the command history.

2. Error Reporting and Warnings

When an operation fails or requires user attention, Blender reports the feedback through the Info Editor. Messages are categorized to help you quickly identify issues:

  • Information (Info): Confirms successful operations, such as saving a file or completing a render.
  • Warnings: Highlights potential issues that do not stop the program, such as missing textures or unapplied scale.
  • Errors: Details failed operations, such as broken Python scripts or invalid tool inputs.

3. Log Filtering and Search

As a scene grows complex, the Info Editor can accumulate hundreds of log entries. To make navigation easier, the editor includes built-in filters that let you toggle the visibility of specific message types (Info, Warnings, or Errors) or search for specific commands and keywords.

How to Access and Use the Info Editor

In Blender 2.8 and newer versions, the Info Editor is hidden by default to keep the interface clean, but it can be opened at any time:

  1. Hover your cursor over the corner of any existing editor until the crosshair icon appears.
  2. Click and drag to create a new window split.
  3. Click the Editor Type dropdown menu in the top-left corner of the new window.
  4. Select Info from the General column.

Once open, you can right-click any logged line to copy it to your clipboard, clear the log history, or filter out unwanted message types.
