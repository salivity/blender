Global vs Local Orientation in Blender

In Blender, transform orientations dictate the coordinate axes along which objects move, rotate, and scale. The fundamental difference between global and local orientation comes down to the reference frame being used: Global orientation uses the fixed, unchanging axes of the 3D world space, whereas Local orientation uses the individual object's own coordinate system, which rotates and tilts along with the object.

What is Global Orientation?

Global orientation is the default transform system in Blender. It relies on the absolute world origin \((0, 0, 0)\) and maintains a fixed set of directions throughout your entire scene:

  • X-axis: Left / Right (East / West)
  • Y-axis: Forward / Backward (North / South)
  • Z-axis: Up / Down

No matter how much you rotate, tilt, or flip an object, its global axes never change. Moving an object along the Global Z-axis will always move it straight up toward the sky of the 3D viewport, regardless of which direction the object itself is facing.

What is Local Orientation?

Local orientation is tied directly to the specific object. When an object is created, its local axes align with the global axes. However, as soon as you rotate the object, its local axes rotate with it.

For example, if you model a rocket and tilt it 45 degrees to the side:

  • Global Z-axis still points straight up to the world's ceiling.
  • Local Z-axis now points diagonally in the direction the nose of the rocket is pointing.

Moving the rocket along its Local Z-axis allows it to travel forward in the direction it is facing, rather than floating straight up into the air.

Key Differences at a Glance

Feature Global Orientation Local Orientation
Reference Frame The 3D World Space The Individual Object
Axis Behavior Static (never changes) Dynamic (rotates with the object)
Default Axis Direction Z is always straight up Z points where the object's "top" is facing
Best Used For Leveling objects, world placement Moving objects in the direction they face

How to Switch Between Global and Local in Blender

You can toggle between these orientations using several methods:

  1. Transform Orientation Menu: Click the orientation dropdown menu located at the top center of the 3D Viewport (it defaults to "Global") and select "Local."
  2. Pie Menu Shortcut: Press , (Comma) on your keyboard to open the Orientation Pie Menu, then select Global or Local.
  3. Axis Hotkeys: When transforming an object using a shortcut (such as G for grab, R for rotate, or S for scale):
    • Press the axis key once (e.g., G then Z) to lock to the Global axis.
    • Press the axis key twice (e.g., G then Z then Z) to lock to the Local axis.
