How to Select a Single Edge Loop in Blender

Selecting a single edge loop in Blender is a fundamental modeling skill that allows you to quickly select a contiguous ring of edges across a mesh. By entering Edit Mode and using the shortcut combination of holding Alt (or Option on Mac) while left-clicking an edge, you can instantly highlight an entire edge loop. This article covers the exact steps, mouse positioning, and helpful shortcuts to select single and multiple edge loops efficiently.

Step-by-Step Guide to Edge Loop Selection

  1. Switch to Edit Mode
    Select your 3D object in the viewport and press Tab to switch from Object Mode to Edit Mode.

  2. Enable Edge Select Mode
    Press 2 on your top-row number keys (or click the Edge Select icon in the top-left of the 3D Viewport) to switch to Edge Select mode.

  3. Select the Edge Loop

    • Windows / Linux: Hold Alt and Left-Click directly on the edge you want to follow.
    • macOS: Hold Option and Left-Click directly on the edge you want to follow.

Selecting Multiple Edge Loops or Deselecting

  • Add an Edge Loop: Hold Shift + Alt (or Shift + Option on Mac) and left-click another edge loop to add it to your current selection.
  • Remove an Edge Loop: Hold Shift + Alt (or Shift + Option on Mac) and left-click an already selected edge loop to deselect it.

Edge Loop Selection Rules and Troubleshooting

  • Quad Topology Required: Edge loops rely on four-sided faces (quads) to determine direction. If the loop encounters an n-gon (a face with 5 or more sides), a triangle, or a complex vertex pole, the selection will terminate at that boundary.
  • Linux Window Conflicts: On certain Linux operating systems, holding Alt and left-clicking moves the window. If this happens, rebind your system’s window movement key or change your keymap under Edit > Preferences > Input in Blender.
