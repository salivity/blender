Blender Smoke Simulation Noise Upres Explained

The Noise Upres setting in Blender's gas and smoke simulation system is a detail-enhancing feature that adds fine, high-frequency turbulence to a simulation without requiring the entire physical calculation to run at a massive resolution. By separating the macro motion of the fluid from the micro details, this tool allows artists to iterate quickly on large-scale movement and subsequently bake intricate smoke wisps, fire tendrils, and turbulence in a fraction of the time required for a standard high-resolution bake.

How Noise Upres Works

In Blender’s Mantaflow simulation engine, the domain calculates fluid dynamics based on a 3D grid of voxels determined by the Resolution Divisions setting (the base resolution).

When you enable Noise, Blender takes the velocity vectors and density data from that base simulation and extrapolates them onto a higher-resolution grid using a wavelet noise algorithm. Instead of recalculating the complex Navier-Stokes equations for fluid dynamics at a heavy resolution, Blender applies procedural turbulence over the existing movement.

Key Parameters in the Noise Panel

  • Upres Factor: This is an integer multiplier applied to the base resolution grid. For example, if your base resolution is set to 64 and the Upres Factor is set to 2, the noise detail will be calculated on a grid equivalent to a resolution of 128. An Upres Factor of 3 would yield an effective resolution of 192. Higher numbers yield finer details at the cost of bake time and RAM.
  • Strength: Controls the intensity and visibility of the generated noise. Higher values produce sharp, aggressive turbulence and swirling patterns, while lower values keep the smoke smoother and more diffuse.
  • Scale: Adjusts the frequency or size of the noise patterns. Smaller scale values create larger, broader noise waves, while larger scale values introduce tiny, intricate eddies.
  • Time: Dictates the animation speed of the noise field over time. Increasing this value makes the micro-turbulence evolve and shift faster relative to the base fluid flow.

The Recommended Workflow

Using Noise Upres dramatically streamlines the visual effects pipeline in Blender:

  1. Simulate Base Motion: Keep the domain’s base resolution low (e.g., 32 to 64 divisions) and bake only the fluid physics to quickly block out and approve the overall shape, speed, and trajectory of the fire or smoke.
  2. Enable and Tune Noise: Once the general motion is finalized, enable the Noise checkbox, set an Upres Factor (typically 2 or 3 for final renders), and adjust the strength and scale.
  3. Bake Noise: Bake the noise cache separately. Because the underlying physics are already cached, Blender only needs to compute the surface-level turbulence grid, saving significant processing time and memory overhead compared to running a native high-resolution simulation.
