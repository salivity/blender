How to Change Curve Point Handle Type in Blender

Changing the handle type of a curve point in Blender allows you to control how curves bend, create sharp corners, or smooth out transitions between control points. This guide covers the essential shortcut key, menu navigation, and explanations of the four primary curve handle types—Automatic, Vector, Aligned, and Free—so you can precisely alter your curve geometry in Edit Mode.

Step-by-Step Guide

  1. Enter Edit Mode: Select your curve object in the viewport and press Tab to switch to Edit Mode.
  2. Select the Point: Click on the control point (or individual handle) you want to modify. You can select multiple points by holding Shift.
  3. Open Handle Menu: Press V on your keyboard.
  4. Select Handle Type: Choose the desired handle type from the pop-up menu.

Alternatively, you can access the same menu by going to the top bar and selecting Curve > Control Points > Set Handle Type.

Blender Handle Types Explained

  • Automatic: Calculates smooth curves automatically depending on the positions of adjacent control points.
  • Vector: Points directly toward the adjacent control points, producing straight lines and sharp corners.
  • Aligned: Locks both handles into a straight line to maintain a smooth curve, while still allowing you to adjust individual handle lengths.
  • Free: Completely decouples the handles, allowing each side to be rotated and scaled independently for custom angles and asymmetrical shapes.
