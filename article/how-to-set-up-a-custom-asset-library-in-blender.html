How to Set Up a Custom Asset Library in Blender

This guide provides a step-by-step walkthrough on how to configure a custom asset library directory in Blender. By setting up a dedicated file path in your preferences, you can store, organize, and access reusable 3D models, materials, poses, and node groups across all your Blender projects seamlessly using the Asset Browser.

Step 1: Open Blender Preferences

  1. Launch Blender.
  2. In the top menu bar, click on Edit.
  3. Select Preferences from the drop-down menu (or press Ctrl + , on Windows/Linux or Cmd + , on macOS).

Step 2: Navigate to File Paths

  1. In the Preferences window, look at the sidebar on the left.
  2. Click on the File Paths tab.

Step 3: Add a New Asset Library

  1. Scroll down to the Asset Libraries section within the File Paths settings.
  2. Click the + (Add Asset Library) button on the right side of the list.
  3. A file browser window will appear. Navigate to the folder on your computer where your asset .blend files are stored (or create a new dedicated folder).
  4. Click Add Asset Library to confirm the directory.

Step 4: Name and Configure the Library

  1. Once added, the library will appear in the Asset Libraries list.
  2. Double-click the default name field to rename the library (e.g., "Kitbash Assets", "Materials", or "Characters").
  3. Set your preferred Import Method using the drop-down menu next to the path:
    • Append: Copies the asset directly into your current file. Changes to the original asset file will not affect your project.
    • Append (Reuse Data): Copies the asset into your file but reuses existing data (like materials) if already present in the scene.
    • Link: Creates a reference to the original file. Any updates to the source asset will automatically update in your scene, but the asset data cannot be edited directly within the current project.

Step 5: Save Preferences

Blender automatically saves preferences by default. If auto-save is disabled:

  1. Click the hamburger menu (three horizontal lines) in the bottom-left corner of the Preferences window.
  2. Click Save Preferences.

Step 6: Access Your Library in the Asset Browser

  1. Change any editor window in Blender to the Asset Browser (Editor Type > Asset Browser, or press Shift + F1).
  2. Open the source drop-down menu in the top-left corner (defaults to "Current File").
  3. Select your newly created custom library name from the list to view and drag your assets directly into the 3D Viewport.
