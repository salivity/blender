How to Frame Selected Object in Blender

Framing a selected object in Blender allows you to instantly center and zoom your viewport camera onto your chosen target. The primary keyboard shortcut for this essential function is the Numpad Period (.) key. This guide covers how to use this default shortcut, how to frame objects if your keyboard lacks a numeric keypad, and how the shortcut applies across various Blender editors.

The Primary Shortcut: Numpad Period (.)

To quickly focus your view on any object or mesh component in Blender:

  1. Select the object, vertex, edge, or face in your workspace.
  2. Press the Numpad Period (.) key on your numeric keypad.

Executing this command instantly zooms in and centers the viewport on the selected item. Additionally, it adjusts the viewport’s rotation pivot point to the origin of the selected object, making orbit navigation much smoother.

How to Frame Selected Without a Numpad

If you are using a laptop or a compact keyboard without a dedicated numeric keypad, you can frame selected objects using alternative methods:

Method 1: The View Menu

  1. Select your object.
  2. Navigate to the top-left of the 3D Viewport header.
  3. Click View > Frame Selected.

Method 2: The View Navigation Pie Menu

  1. Select your object.
  2. Press the Tilde / Grave Accent (~) key to open the View Navigation pie menu.
  3. Select View Selected (or press 3 while the pie menu is active).

Method 3: Enable “Emulate Numpad”

  1. Go to Edit > Preferences > Input.
  2. Check the box for Emulate Numpad.
  3. You can now use the main row Period (.) key or standard numbers for Numpad navigation features.

Framing Objects in Other Blender Editors

The Numpad . shortcut is consistent across almost all of Blender’s different workspaces:

  • Outliner: Select an object in the 3D Viewport and press Numpad . over the Outliner to instantly expand the tree and highlight the active item.
  • Shader / Geometry Node Editor: Select a node and press Numpad . to center the workspace directly on that node.
  • UV Editor & Image Editor: Focuses on selected UV islands, vertices, or images.
  • Graph Editor & Dope Sheet: Centers the keyframes of the selected object within the timeline view.
