How to Use an Object as a Particle in Blender

This guide explains how to replace default particle points in Blender with a custom 3D mesh using particle instancing. By switching the particle render settings from the default halo to an object instance, you can scatter, duplicate, and animate complex geometry across any emitter surface efficiently.

1. Prepare Your Objects

  1. Open your Blender scene.
  2. Ensure you have two objects:
    • Emitter Object: The mesh that will emit or scatter the particles (e.g., a plane or sphere).
    • Instance Object: The custom 3D object you want to appear as the particles (e.g., a rock, leaf, or coin).

2. Add a Particle System to the Emitter

  1. Select the Emitter Object in the 3D Viewport.
  2. Navigate to the Particle Properties tab in the Properties editor (the icon with three connected dots).
  3. Click the + (plus) button to add a new particle system.
  4. Choose either Emitter (for dynamic simulations like sparks or debris) or Hair (for static scattering like grass or foliage).

3. Change the Render Settings to Object Instance

  1. In the Particle Properties panel, scroll down to the Render section.
  2. Change the Render As dropdown from Halo to Object.
  3. Locate the Object sub-panel that appears below.
  4. In the Instance Object field, select your custom mesh by clicking the eyedropper tool and clicking the object in the viewport, or by choosing it from the dropdown list.

4. Adjust Scale and Orientation

  1. Scale: Adjust the Scale slider under the Render section to control the size of the instanced objects. Use Scale Randomness to add variation.
  2. Rotation:
    • Check the Rotation box in the main particle settings.
    • Expand the Rotation panel, change the Orientation Axis (e.g., to Normal or Velocity / Hair), and adjust the Randomize sliders to vary the direction each instance points.
    • If using custom rotation from the source object, check Object Rotation within the Render panel.

5. Manage the Original Instance Object

To prevent the original instance object from appearing in your final render in its starting position:

  • Move the original object to a hidden collection, or
  • Move it outside of the camera’s field of view.
