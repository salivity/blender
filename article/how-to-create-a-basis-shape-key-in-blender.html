How to Create a Basis Shape Key in Blender

Creating a Basis shape key in Blender is the essential first step for setting up non-destructive mesh deformations, such as facial expressions or character rigging adjustments. The Basis shape key acts as the default, undeformed reference state of your 3D model from which all other shape variations are calculated. This quick guide walks you through selecting your mesh, navigating the Object Data Properties tab, and initializing the default Basis shape key.

Steps to Create a Basis Shape Key

  1. Select Your Object: Left-click your 3D mesh in the viewport while in Object Mode.
  2. Open Object Data Properties: In the Properties editor (usually on the right side of the interface), click the Object Data Properties icon, which resembles a green triangle with vertices.
  3. Locate the Shape Keys Panel: Expand the Shape Keys section within the panel.
  4. Add the Basis Key: Click the + (Plus) button on the right side of the panel.

Because this is the first shape key assigned to the object, Blender automatically designates and names it "Basis".

How to Use the Basis Shape Key

  • Default Reference: The Basis key stores the default position of all vertices on your mesh. Keep this key selected whenever you want to view or return to your un-deformed model.
  • Creating Secondary Keys: To create an actual mesh variation (such as a smile or an eye blink), click the + button a second time. This creates a new key (e.g., "Key 1").
  • Editing Deformations: Select the new key ("Key 1"), switch to Edit Mode (Tab), and adjust your mesh's vertices. The changes will only apply to that specific shape key, leaving the original "Basis" key untouched.
  • Controlling Deformations: Switch back to Object Mode and adjust the Value slider next to your secondary key to blend between the original Basis shape and the new deformation.
