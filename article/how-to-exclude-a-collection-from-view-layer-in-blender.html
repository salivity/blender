How to Exclude a Collection from View Layer in Blender

Excluding a collection from a view layer in Blender removes that collection’s objects from both the viewport display and the final render for the active view layer. This process is essential for managing complex scenes, optimizing performance, and setting up multi-pass rendering pipelines without permanently deleting assets. This guide provides clear, step-by-step instructions on how to toggle and exclude collections directly within the Blender Outliner.

Method 1: Unchecking the Collection Checkbox

The fastest way to exclude a collection from your active view layer is using the default checkbox in the Outliner window.

  1. Open the Outliner: Locate the Outliner panel (usually in the top-right corner of the default Blender workspace).
  2. Select the Active View Layer: Ensure the view layer dropdown menu at the top right of the Blender interface is set to the view layer you want to modify.
  3. Locate the Collection: Find the specific collection in the Outliner hierarchy.
  4. Uncheck the Collection: Click the checkbox located immediately to the left of the collection's name.

Unchecking this box completely excludes the collection from the active view layer. The objects in the collection will not appear in the 3D Viewport or in renders for that specific view layer, though they remain intact in the scene.

Method 2: Disabling Collections via Restriction Toggles

If you need more control over visibility (such as hiding an item in the viewport while keeping it visible in renders, or vice versa), use restriction toggles.

  1. Open Filter Options: At the top right of the Outliner panel, click the Filter icon (looks like a funnel).
  2. Enable Toggles: Under the Restriction Toggles section, enable the icons you need:
    • Disable in Viewports (Monitor icon): Hides the collection in the 3D viewport.
    • Disable in Renders (Camera icon): Prevents the collection from rendering while keeping it visible in the viewport.
  3. Apply Toggles: Click the corresponding icons next to your collection name in the Outliner to toggle their state on or off.

Key Differences: Hiding vs. Excluding

  • Hiding (Eye Icon): Temporarily hides the collection in the current viewport. Hidden objects are still calculated during render time and remain loaded in memory.
  • Excluding (Checkbox): Removes the collection from the active View Layer entirely. Excluded objects are not loaded into memory for that layer and will not render, saving system resources and reducing render times.
