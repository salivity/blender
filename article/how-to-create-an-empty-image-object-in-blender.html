How to Create an Empty Image Object in Blender

Creating an empty image object in Blender allows 3D artists to import reference photos, blueprints, or textures directly into the 3D viewport without adding extra mesh geometry. This guide explains step-by-step how to add an empty image object using keyboard shortcuts or the top menu, assign an image file to it, and adjust key display settings for efficient modeling.

Method 1: Using the Add Menu

  1. Open the 3D Viewport: Ensure you are in Object Mode.
  2. Open the Add Menu: Press Shift + A on your keyboard, or click Add in the top-left corner of the 3D Viewport.
  3. Select Image: Hover over Image in the dropdown menu.
  4. Choose Image Type:
    • Reference: Creates an empty image object that scales and moves in 3D space, visible from both sides by default.
    • Background: Creates an empty image object designed to stay behind other objects, ideal for tracing blueprints.
  5. Load the File: Select your image file in the file browser window and click Load Reference Image (or Background Image).

Method 2: Drag and Drop

  1. Open your computer’s file explorer.
  2. Click and drag an image file directly from your folder into the Blender 3D Viewport.
  3. Blender automatically creates an empty image object at the location of your cursor aligned to your current view.

Method 3: Converting an Existing Empty Object

  1. Press Shift + A and select Empty > Plain Axes (or any other empty style).
  2. Select the created Empty object.
  3. Navigate to the Properties Panel on the right side of the screen and click the Object Data Properties tab (icon looks like a small picture inside a frame).
  4. Change the Display As setting to Image.
  5. Click Open to select your image file.

Key Settings for Empty Image Objects

Adjust these settings inside the Object Data Properties tab to tailor the image object to your workflow:

  • Opacity: Check the Opacity box and lower the slider to make the reference image semi-transparent while modeling.
  • Depth: Change this setting to Front to keep the image superimposed over your 3D geometry, or Back to keep it behind your scene.
  • Side: Choose whether the image is visible from Both, Front, or Back sides to prevent visual clutter when navigating around your model.
  • Display Perspective/Orthographic: Toggle these options to show or hide the image depending on whether you are viewing the scene in Perspective or Orthographic mode.
