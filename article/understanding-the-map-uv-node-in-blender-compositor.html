Understanding the Map UV Node in Blender Compositor

The Map UV node in Blender’s Compositor allows artists to map new 2D textures onto rendered 3D objects during post-processing using the UV render pass. By utilizing the geometric UV coordinates captured during the initial render, this node enables seamless texture swapping, screen replacements, and graphic updates without the need to re-render the entire 3D scene.

How the Map UV Node Works

The Map UV node works by taking spatial UV coordinate data and using it to distort and place a 2D image onto the corresponding geometry in the render.

The node requires two main inputs:

  • Image: The new 2D texture, image, or video sequence you want to apply to the rendered object.
  • UV: The UV vector data generated by Blender's render engine, typically pulled directly from the UV Render Pass of the Render Layers node.

The node calculates where each pixel of the input image belongs on the 2D render based on the red and green channel values of the UV pass, which represent the U and V spatial coordinates.

Standard Workflow Setup

To use the Map UV node effectively, follow this standard setup:

  1. Enable the UV Pass: In the View Layer properties, navigate to the Passes panel and check the UV box under the Data section.
  2. Open the Compositor: Switch to the Compositing workspace and ensure Use Nodes is enabled.
  3. Add the Map UV Node: Press Shift + A, navigate to Distort, and select Map UV.
  4. Connect the Passes: Connect the UV output from the Render Layers node to the UV input of the Map UV node.
  5. Add the Texture: Add an Image node containing your replacement graphic and connect its output to the Image input of the Map UV node.
  6. Blend with the Render: Use an Alpha Over or Mix Color node to composite the mapped texture back over the original render.

Common Use Cases

  • Screen and Display Replacement: Placing dynamic video footage or UI graphics onto rendered monitors, smartphones, or television screens.
  • Branding and Label Iteration: Swapping product labels, logos, or packaging artwork for client revisions without spending hours re-rendering complex 3D lighting and geometry.
  • Texture Animation: Applying animated textures to moving 3D objects directly in the 2D compositing phase.

Practical Considerations

Because the Map UV node applies a flat 2D image over the render, the replacement texture will not automatically inherit the original scene's lighting, shadows, or reflections. To achieve photorealistic results, you must multiply or blend the mapped image with lighting passes (such as the Diffuse Direct and Indirect passes) or use the original render's brightness data as a shading mask. Additionally, using an Object Index pass, Material Index pass, or Cryptomatte is recommended to restrict the mapping strictly to the target object.
