Setup Orthographic Reference Images in Blender

Setting up background reference images aligned to specific orthographic views in Blender is an essential step for accurate 3D modeling, sculpting, and character design. This guide provides a straightforward method to import blueprint or reference artwork directly into front, side, and top orthographic viewports, adjust visibility settings to prevent clutter, and lock the images so they do not interfere with your modeling workflow.

Step 1: Switch to an Orthographic View

Before importing your image, you must align your viewport to the desired orthographic perspective:

  • Front View: Press Numpad 1
  • Right Side View: Press Numpad 3
  • Top View: Press Numpad 7
  • Opposite Views (Left/Back/Bottom): Hold Ctrl while pressing the corresponding Numpad key (e.g., Ctrl + Numpad 1 for Back view).

Ensure you are in Orthographic mode rather than Perspective mode (toggle with Numpad 5).

Step 2: Add the Reference Image

Once the viewport is aligned:

  1. Press Shift + A to open the Add menu.
  2. Navigate to Image and select Reference.
  3. Locate and select your image file, then click Load Reference Image.

Alternatively, you can drag and drop an image file directly from your operating system's file browser into the Blender viewport while in the orthographic view.

Step 3: Configure Reference Image Properties

Select the reference image and open the Object Data Properties tab (represented by an image icon in the Properties panel on the right) to configure its display behavior:

  • Show in Orthographic / Perspective: Uncheck Perspective if you only want the reference to appear in flat orthographic views and disappear when rotating the 3D viewport.
  • Depth: Set this to Back if you want the reference image to always appear behind your 3D geometry, or Front if you want it in front of the model.
  • Opacity: Enable the Opacity checkbox and lower the slider (e.g., to 0.5) to make the image semi-transparent, allowing you to see your wireframe and mesh clearly through it.
  • Side: Choose Front or Back if you only want the reference visible from one specific viewing direction.

Step 4: Position and Scale

Use standard Blender transform shortcuts to align the image with the scene's origin:

  • Press G to move the image.
  • Press S to scale the image.
  • Press R to rotate the image if necessary.

Step 5: Lock the Reference Image

To prevent accidentally selecting or moving the reference image while working on your 3D mesh:

  1. Go to the Outliner (top-right panel).
  2. Click the Filter funnel icon at the top of the Outliner.
  3. Enable the Selectable toggle (arrow icon).
  4. Click the arrow icon next to your reference image in the Outliner list to disable selection for that object.
