How to Exclude an Object From a Light in Blender

Blender allows you to control exactly which objects interact with specific light sources using the Light Linking feature introduced in Blender 4.0. This guide explains how to use Light Linking in the Cycles render engine to exclude a specific mesh from receiving illumination from any chosen lamp in your scene.

Prerequisites

Light Linking is a native feature available in Blender 4.0 and newer and is currently supported exclusively by the Cycles render engine. Ensure your render engine is set to Cycles in the Render Properties tab before proceeding.

Method 1: Using the Outliner (Fastest)

  1. Switch Outliner Mode: In the top-left corner of the Outliner panel, click the display mode dropdown (which defaults to View Layer) and select Light Linking.
  2. Select the Light: Click on the lamp or light source in the Outliner that you want to adjust.
  3. Assign Objects: Drag the mesh you want to manage into the light's collection list in the Outliner.
  4. Set to Exclude: By default, dragged objects are set to receive light. Click the state icon next to the object name to toggle it to Exclude (represented by a minus or restriction icon). The light will now illuminate everything in the scene except this specific mesh.

Method 2: Using the Object Properties Panel

  1. Select the Light Source: In the 3D Viewport or Outliner, select the lamp you want to configure.
  2. Open Shading Settings: Go to the Object Properties tab (the orange square icon) in the Properties panel.
  3. Enable Light Linking: Scroll down and expand the Shading panel, then open the Light Linking sub-panel.
  4. Create a Collection: Click the New button to create a dedicated light linking collection for that lamp.
  5. Add the Mesh: Drag the mesh object from the Outliner directly into the Light Linking list field, or use the dropdown to add the object or a collection of objects.
  6. Configure Link State: Set the inclusion state of the linked object to exclude it from the light calculation.

Excluding Shadows (Shadow Linking)

If you also want to prevent the excluded mesh from casting shadows generated by that same lamp:

  1. Select the light source.
  2. In Object Properties > Shading, open the Shadow Linking panel directly beneath Light Linking.
  3. Click New and add the mesh object to the Shadow Linking list, setting its state to exclude.
