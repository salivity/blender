Blender Texture Paint 3D Cursor Clone Tool

The 3D cursor clone source in Blender's Texture Paint mode enables artists to sample and duplicate surface textures directly from a defined location in 3D space rather than from a flat 2D image. By setting the 3D cursor as the clone source anchor, you can paint texture details across complex geometry and mismatched UV seams with spatial continuity, using the cursor's position as the reference origin.

How the 3D Cursor Clone Source Works

When painting with the Clone Brush in Blender, you can choose between two main clone sources: Image and 3D Cursor.

When 3D Cursor is selected, Blender uses the current position of the 3D cursor as the reference point for the clone offset. As you paint onto the model, the brush samples existing texture pixels relative to the distance and orientation between the cursor and the stroke area. This projects the texture from one part of the mesh onto another in 3D space, bypassing the limitations of 2D UV mapping.

How to Use the 3D Cursor Clone Source

  1. Switch to Texture Paint Mode: Select your mesh and switch the interaction mode to Texture Paint.
  2. Select the Clone Tool: Choose the Clone brush from the toolbar or the Active Tool settings.
  3. Set the Clone Source: In the Tool Settings panel (or the N-Panel under Tool), locate the Clone settings and set the Source option to 3D Cursor.
  4. Position the 3D Cursor: Place the 3D cursor at the exact point on your model that you want to clone from using Shift + Right Click (or the 3D Cursor tool).
  5. Paint the Texture: Move your brush to the target area and paint. The brush will sample the texture around the 3D cursor and apply it to the surface under your stroke.

Key Benefits

  • Seamless UV Transitions: Painting across separate UV islands often creates visible seams. The 3D cursor clone method samples directly in 3D space, ensuring seamless pattern continuity across split edges.
  • Detail Duplication: It allows quick replication of specific surface features, such as scars, bolts, or fabric patterns, across different parts of a character or prop.
  • No Secondary Image Required: Unlike 2D image cloning, you do not need to load or align a secondary texture file to transfer texture details from one area of a mesh to another.
