What Are Face Sets in Blender Sculpting?

Face Sets in Blender sculpting are color-coded groupings of geometry that allow 3D artists to easily hide, isolate, mask, and sculpt specific regions of a mesh. Acting as an advanced visibility and selection system, Face Sets streamline complex sculpting workflows by providing precise control over targeted areas of a model without requiring manual, time-consuming masking.

How Face Sets Work

When you assign a Face Set to a mesh in Sculpt Mode, Blender displays that group of faces with a unique overlay color. These colors are for visual reference only and do not affect rendering or materials.

By grouping faces into distinct sets, you can interact with individual parts of your mesh independently of the rest of the object.

Key Benefits and Features

  • Quick Isolation: Hovering over a Face Set and pressing H instantly hides all other Face Sets, allowing you to focus on detailed work without adjacent geometry blocking your view. Pressing Alt + H unhides everything.
  • Auto-Masking: Blender includes an Auto-Masking feature for brushes that can restrict your strokes strictly to the active Face Set you start painting on, preventing accidental sculpt strokes on surrounding areas.
  • Easy Geometry Extraction: Face Sets can be converted directly into separate objects, masks, or cloth simulation boundaries, making them useful for creating clothing, armor, and hard-surface panels.
  • Pose and Deformation: Tools like the Pose Brush can use Face Sets as joint boundaries, making it simple to pose character limbs and fingers naturally.

Common Ways to Create Face Sets

  1. Draw Face Sets Brush: Paint directly on the mesh surface to create new colored regions or expand existing ones.
  2. From Mask (Ctrl + W): Create a mask on your mesh, then convert that masked area directly into a new Face Set.
  3. From Topology and Features: Automatically generate Face Sets based on UV seams, existing materials, face maps, or loose mesh parts using the Face Sets menu at the top of the Sculpt viewport.
  4. Box and Lasso Tools: Use the Box Face Set or Lasso Face Set tools to quickly select rectangular or custom-shaped regions on your model.

Essential Face Set Shortcuts

  • Ctrl + W: Create a Face Set from the current mask.
  • H: Hide all geometry except the Face Set directly under the mouse cursor.
  • Shift + H: Hide the Face Set directly under the mouse cursor.
  • Alt + H: Reveal all hidden geometry and Face Sets.
