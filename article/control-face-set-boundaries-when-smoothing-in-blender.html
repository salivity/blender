Control Face Set Boundaries When Smoothing in Blender

Controlling face set boundaries while using smoothing filters in Blender Sculpt Mode is essential for maintaining distinct topological regions, preventing border distortion, and preserving hard transitions between groups. This article explains how to configure Auto-Masking settings and the Mesh Filter tool to effectively constrain smoothing operations to active face sets or completely lock their boundaries.

Using Auto-Masking to Lock Face Set Boundaries

The primary way to protect face set edges in Sculpt Mode is through the Auto-Masking menu. This global setting dictates how sculpting brushes and mesh filters affect your geometry.

  1. Switch to Sculpt Mode.
  2. Locate the Auto-Masking popover menu in the top header bar (or in the Tool panel on the right sidebar).
  3. Toggle the following options based on your workflow needs:
    • Face Sets: Restricts the smoothing operation strictly to the face set where the cursor starts. Surrounding face sets remain untouched.
    • Face Sets Boundary: Prevents the shared border vertices between two or more face sets from shifting or shrinking when smoothed. This preserves clean, sharp demarcation lines across the model.

Applying the Smoothing Mesh Filter

Once Auto-Masking is configured, you can apply a smooth filter across the entire mesh or selected sections without blurring the perimeter of your face sets.

  1. Select the Mesh Filter tool from the left toolbar (or press Shift + Space, then select Mesh Filter).
  2. In the Tool Settings at the top or in the Active Tool properties tab, set the Filter Type to Smooth.
  3. Confirm that the Face Sets Boundary option remains checked in the Auto-Masking settings.
  4. Click and drag horizontally in the 3D Viewport to apply the smoothing effect.

The interior geometry of your face sets will smooth out according to the filter strength, while the edges defining each individual face set will hold their original shape and position.

Isolate Face Sets for Complete Control

If you need absolute isolation without boundary interaction:

  • Hover over a face set and press Shift + H to hide all other face sets.
  • Apply the Smooth Mesh Filter freely; hidden geometry and its shared borders will remain fully protected.
  • Press Alt + H to unhide all face sets once smoothing is complete.
