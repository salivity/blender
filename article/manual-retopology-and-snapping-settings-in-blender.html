Manual Retopology and Snapping Settings in Blender

Manual retopology is the process of creating a clean, optimized, low-polygon mesh over a high-resolution 3D sculpt by hand. This article explains what manual retopology is, why it is essential for 3D production pipelines, and the specific snapping settings in Blender required to efficiently project new geometry onto high-poly surfaces.

What is Manual Retopology?

Manual retopology is the deliberate reconstruction of a 3D model's surface using standard modeling tools. While sculpting or 3D scanning produces high-density meshes with millions of irregularly distributed polygons (often triangles), these models are unsuitable for rigging, animation, or real-time rendering in game engines.

During manual retopology, an artist creates a new mesh comprised predominantly of four-sided polygons (quads). The artist hand-places geometry to create clean "edge loops" that follow the natural contours and muscle flows of the subject. This manual approach ensures predictable deformation during animation, easier UV unwrapping, and optimal performance in real-time environments.

Essential Snapping Settings for Retopology in Blender

Blender provides built-in snapping tools that allow new vertices, edges, and faces to stick directly to the surface of the underlying high-poly reference mesh. To set up Blender for manual retopology, configure the following snapping settings in the top header of the 3D Viewport:

1. Snap Mode and Target

  • Enable Snapping: Click the Magnet icon or press Shift + Tab to activate the snapping tool.
  • Snap Base: Set this to Closest or Center so the actively transformed element snaps directly to the target.
  • Snap To: Set the snapping target to Face Project (or Face Nearest in newer Blender versions). This forces new geometry to stick to the faces of the underlying high-poly mesh rather than floating in 3D space.

2. Project Individual Elements

When transforming multiple vertices, edges, or extruding full edge loops, enable Project Individual Elements.

  • Without this setting, Blender calculates an average transformation point for the selected group, causing some vertices to hover above or sink below the reference surface.
  • With this setting enabled, every single vertex in the selection independently finds and snaps to the nearest point on the target surface.

3. Target Selection and Constraints

  • Include / Exclude Options: Ensure snapping is configured to target the high-poly reference. Under the snap options popover, you can enable Exclude Non-Selectable and disable selection on your high-poly object in the Outliner. This prevents the retopology mesh from accidentally snapping to its own faces instead of the high-poly surface beneath it.

Complementary Retopology Tools

To make manual retopology with snapping more efficient, use these companion features alongside the snapping settings:

  • Auto Merge Vertices: Enable the Auto Merge toggle (located in the top-right of the 3D Viewport) and set a low threshold. When extruding edges together, vertices that snap into the same location will automatically weld into a single vertex.
  • In Front Display: In the Object Properties > Viewport Display panel of your retopology mesh, check In Front. This renders your low-poly mesh on top of the high-poly reference, preventing it from clipping through the sculpt while you work.
  • Shrinkwrap Modifier: Adding a Shrinkwrap Modifier targeted to the high-poly mesh serves as a safety net, ensuring any vertices moved without snapping still conform tightly to the target surface.
