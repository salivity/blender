How to Control Vertex Crease in Blender

This guide explains how to control and adjust vertex creasing when using the Subdivision Surface modifier in Blender. You will learn how vertex creasing works, how to assign and modify crease weights using interface controls and viewport shortcuts, and how to fine-tune your mesh geometry to achieve precise sharp points without adding extra support loops.

What is Vertex Creasing?

Vertex creasing allows you to control the sharpness of individual vertices when a mesh is subdivided using the Catmull-Clark algorithm. While edge creasing hardens entire edges, vertex creasing pinches the subdivision effect toward a specific vertex, letting you create sharp corners, spikes, or semi-hard transitions directly on the base mesh.

Step-by-Step: Controlling Vertex Crease

  1. Add the Modifier: Select your object in Object Mode, go to the Modifier Properties tab (wrench icon), click Add Modifier, and select Subdivision Surface (or press Ctrl + 1, Ctrl + 2, etc.). Ensure the subdivision algorithm is set to Catmull-Clark.
  2. Enter Edit Mode: Press Tab to enter Edit Mode.
  3. Select Vertices: Press 1 on your alphanumeric keyboard to switch to Vertex Select mode, then select the vertex or vertices you want to crease.
  4. Adjust Crease Weight:
    • Using the Sidebar: Press N to open the Sidebar panel on the right side of the 3D Viewport. Go to the Item tab and find the Transform section. Locate the Vertex Crease slider and enter a value between 0.00 (fully smoothed) and 1.00 (completely sharp).
    • Using the Vertex Menu: With your vertices selected, navigate to the top viewport header and choose Vertex > Vertex Crease (or press F3 and type "Vertex Crease"). Move your mouse to interactively adjust the weight, or type a precise numerical value and press Enter.

Key Behaviors and Tips

  • Weight Values: A weight of 0.00 applies default Catmull-Clark smoothing. A weight of 1.00 keeps the vertex pinned to its exact cage position. Intermediate values (e.g., 0.50) yield semi-sharp transitions.
  • Viewport Color Coding: In Edit Mode, vertices with a crease weight greater than zero are highlighted with a distinct color (typically a light magenta or purple, depending on your Blender theme).
  • Combining with Edge Crease: You can combine vertex creasing with edge creasing (Shift + E) to create complex mechanical or organic shapes without needing to insert destructive bevels or loop cuts.
