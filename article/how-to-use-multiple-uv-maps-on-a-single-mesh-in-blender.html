How to Use Multiple UV Maps on a Single Mesh in Blender

Managing multiple UV maps on a single mesh in Blender allows you to apply different texture layouts, such as separate channels for base colors, decals, ambient occlusion, or lightmaps, to the same 3D object. This process involves creating new UV channels in the Object Data Properties tab, editing each map individually in the UV Editor, and directing specific textures to their corresponding UV maps using the UV Map node inside the Shader Editor.

1. Creating and Managing UV Map Channels

To add, remove, or rename UV maps for your mesh, use the Object Data Properties panel:

  1. Select your 3D mesh in the 3D Viewport.
  2. Go to the Object Data Properties tab (the green triangle icon in the Properties Editor).
  3. Expand the UV Maps section.
  4. Click the + (Plus) button to add a new UV map. Blender will duplicate the currently selected UV layout to the new map.
  5. Double-click the newly created UV map to rename it (for example, UV_Base and UV_Decal).
  6. Click the Camera Icon next to a UV map to set it as the active rendering map when no explicit map is specified in the shader.

2. Editing Individual UV Maps

Each UV map stores its own unique layout. To edit a specific map:

  1. Select the target UV map in the UV Maps list to highlight it.
  2. Switch to Edit Mode (Tab).
  3. Open the UV Editing workspace or set a window to the UV Editor.
  4. Unwrap or adjust the vertices. Changes made will only apply to the selected UV map channel.

3. Linking UV Maps to Materials in the Shader Editor

To tell Blender which texture image should use which UV map, you must assign them explicitly in the material node tree:

  1. Open the Shader Editor with your object selected.
  2. Press Shift + A and navigate to Input > UV Map to add a UV Map node.
  3. On the UV Map node, click the dropdown menu and select the specific UV map you created (e.g., UV_Decal).
  4. Connect the UV output vector of the UV Map node into the Vector input of the corresponding Image Texture node.
  5. Repeat this step for other textures requiring different UV map layouts.
