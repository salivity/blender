How to Bake a Diffuse Texture in Blender

Baking a diffuse texture in Blender transfers color, base materials, and lighting information from procedural shaders or complex material setups into a single 2D image map. This process is essential for optimizing 3D assets for game engines like Unity and Unreal Engine, as well as improving viewport performance. This guide provides a clear, step-by-step walkthrough to successfully bake a diffuse texture using Blender’s Cycles render engine.

Step 1: Unwrap the 3D Model

Before baking, your 3D mesh must have a clean UV map so Blender knows how to project the 2D texture onto the 3D surface.

  1. Select your object and press Tab to enter Edit Mode.
  2. Press A to select all vertices.
  3. Press U and select Unwrap (or Smart UV Project for quick automatic unwrapping).
  4. Verify the layout by opening the UV Editor workspace. Ensure no UV faces are overlapping.

Step 2: Create a Target Image Texture

You need an empty image file inside Blender to store the baked diffuse data.

  1. Switch to the Shader Editor workspace with your object selected.
  2. Press Shift + A and select Texture > Image Texture.
  3. Click New on the node.
  4. Name your texture (e.g., “Diffuse_Bake”), set the desired resolution (such as 2048 x 2048), and click OK.
  5. Important: Keep this new Image Texture node selected (highlighted with a white border), but do not connect its outputs to any other nodes.

Step 3: Switch the Render Engine to Cycles

Blender only supports texture baking in the Cycles engine.

  1. Go to the Properties Panel on the right side of the screen.
  2. Select the Render Properties tab (camera icon).
  3. Change the Render Engine from EEVEE to Cycles.

Step 4: Configure the Bake Settings

Set up the render parameters specifically for a diffuse map.

  1. Scroll down to the Bake section in the Render Properties tab.
  2. Change the Bake Type to Diffuse.
  3. Under the Influence section, choose what information to bake:
    • Base Color only: Uncheck Direct and Indirect lighting options. This leaves only Color checked, producing a clean, flat texture free of shadows and highlights (ideal for game engines).
    • Full Lighting: Keep Direct and Indirect checked if you want light and shadow information permanently painted onto the surface.
  4. Set the Margin (under Output settings) to 16px to prevent visible seams along the UV edges.

Step 5: Execute the Bake

  1. Ensure your object is selected in the 3D Viewport.
  2. Ensure the empty target Image Texture node is selected in the Shader Editor.
  3. In the Render Properties tab under the Bake section, click the Bake button.
  4. Wait for the progress bar at the bottom of the screen to finish.

Step 6: Save the Baked Image

Blender does not automatically save baked images to your hard drive. If you close Blender without saving, the baked data will be lost.

  1. Open the Image Editor window.
  2. Select your baked texture from the image dropdown menu at the top.
  3. Click Image in the top menu bar and select Save As….
  4. Choose your desired file format (e.g., PNG or JPEG) and save the file to your computer.
