How to Create Curve Profiles with Blender Curve Pen

This guide explains how to quickly design and extrude custom 3D shapes using the Curve Pen tool and the built-in bevel profile system in Blender. By combining direct curve drawing with the curve geometry settings, you can generate instant moldings, pipes, cables, and architectural profiles directly in the 3D Viewport without manual extrusion.

1. Add a Curve and Activate the Curve Pen

  1. Press Shift + A in the 3D Viewport and select Curve > Bezier.
  2. Press Tab to enter Edit Mode.
  3. Select all existing vertices by pressing A, then press X and choose Delete Vertices to clear the default curve.
  4. Select the Curve Pen tool from the left toolbar (shortcut: Shift + Spacebar, then press P or click the Curve Pen icon).

2. Draw Your Curve Path

  1. Click anywhere in the viewport to place starting and subsequent curve points.
  2. Click and drag while placing a point to create smooth Bezier handles immediately.
  3. Hold Ctrl and click to quickly extend the spline.
  4. To close a shape, click back onto the initial starting point.

3. Generate the Instant Bevel Profile

  1. With the curve selected, open the Object Data Properties tab (the green curve icon) in the Properties panel on the right.
  2. Expand the Geometry section, then expand the Bevel sub-panel.
  3. Switch the Bevel mode from Round to Profile.
  4. Increase the Depth value to give the curve thickness.

4. Customize the Profile Shape

  1. In the Profile curve widget under the Bevel settings, click along the diagonal line to add custom control points.
  2. Move these points to instantly alter the cross-sectional shape of the extruded curve (useful for baseboards, crown moldings, or custom trim).
  3. Use the Preset dropdown at the top of the curve widget to apply pre-made architectural profiles like Crown Molding or Steps.

5. Finalize the Geometry

  1. Check the Fill Caps box under the Bevel settings if you need closed ends on the curve geometry.
  2. Adjust the Resolution Preview U in the Shape panel and the profile resolution to control the mesh density.
  3. When finished, press Tab to return to Object Mode. If standard polygon geometry is required for further editing or exporting, right-click the object and select Convert To > Mesh.
