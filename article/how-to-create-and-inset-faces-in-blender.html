How to Create and Inset Faces in Blender

Creating or insetting a face in Blender is a fundamental 3D modeling technique used to close open mesh geometry or generate inner geometry on an existing polygon. This guide covers how to create a new face between selected vertices or edges using the Fill command, as well as how to use the Inset tool to create inner faces within existing mesh structures.

How to Create a New Face (Fill Tool)

To fill a gap or create a new polygon between existing vertices or edges:

  1. Enter Edit Mode: Select your object and press Tab to switch to Edit Mode.
  2. Select Geometry: Choose Vertex Select mode (press 1) or Edge Select mode (press 2).
  3. Highlight the Target: Hold Shift and select the vertices (at least 3 or 4) or edges that will form the boundary of the new face.
  4. Create the Face: Press F on your keyboard. Blender will instantly generate a face between the selected elements.

How to Inset an Existing Face (Inset Tool)

If "inserting a face" refers to creating a smaller, inset polygon inside an existing face:

  1. Enter Edit Mode: Select your object and press Tab.
  2. Select Face Mode: Press 3 to switch to Face Select mode.
  3. Select the Face: Click on the face you wish to inset.
  4. Activate the Inset Tool: Press I on your keyboard.
  5. Adjust the Size: Move your mouse inward to scale the new inset face.
  6. Confirm: Left-click to set the new face in place.

Helpful Inset Shortcuts

  • Thickness Adjustment: Hold Ctrl while moving the mouse after pressing I to add depth (extrude) along with the inset.
  • Individual Insets: Select multiple faces and press I twice to inset each selected face individually instead of as a single region.

How to Fill Complex Holes (Grid Fill)

For curved or complex open boundary loops containing an even number of vertices:

  1. Select the entire edge loop surrounding the hole (hold Alt and right-click or left-click an edge).
  2. Press Ctrl + F to open the Face menu.
  3. Select Grid Fill to automatically generate a clean grid of faces across the open space.
