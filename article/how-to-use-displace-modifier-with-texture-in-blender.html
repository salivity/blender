How to Use Displace Modifier with Texture in Blender

The Displace modifier in Blender allows you to deform a mesh’s geometry based on the pixel brightness values of a texture. To achieve this effect, you must provide sufficient geometric detail to your object, apply the Displace modifier, assign an image or procedural texture, and adjust key parameters like Strength and Midlevel. This guide provides a step-by-step workflow for setting up and controlling texture-driven displacement in Blender.

Step 1: Prepare the Geometry

The Displace modifier physically shifts vertices. If a mesh lacks sufficient vertices, the displacement will look blocky or fail to appear.

  1. Select your object in the 3D Viewport.
  2. Press Tab to enter Edit Mode.
  3. Right-click the mesh and choose Subdivide.
  4. In the lower-left Subdivide panel, increase the Number of Cuts (e.g., 30 to 50) to create dense geometry.
  5. Press Tab to return to Object Mode.

Step 2: Add the Displace Modifier

  1. Select your object and open the Modifier Properties tab (wrench icon) in the right-hand panel.
  2. Click Add Modifier and select Displace from the Deform column.
  3. In the Displace modifier settings, click New to create a blank texture slot.

Step 3: Assign a Texture

  1. Click the Show Texture in Texture Tab button (the icon with sliders on the far right of the texture box), or select the Texture Properties tab (checkerboard icon) at the bottom of the Properties panel.
  2. Select a texture source from the Type dropdown:
    • Choose Image or Movie to load an external black-and-white heightmap or bump map via the Open button.
    • Choose a Procedural Texture (such as Clouds, Voronoi, or Wood) to generate noise patterns automatically.
  3. Adjust the texture settings (such as Size or Colors) to change the pattern density.

Step 4: Configure Modifier Settings

Return to the Modifier Properties tab to control how the texture deforms the mesh:

  • Coordinates: Select how the texture maps to the object.
    • Local: Uses the object’s local orientation.
    • UV: Recommended when using an image heightmap; requires your mesh to be UV unwrapped.
    • Global: Maps the texture based on world space coordinates.
  • Direction: Determines the vector axis of movement. Normal pushes vertices along their facing directions, while X, Y, or Z restricts movement to a single axis.
  • Strength: Adjusts the distance vertices move. Positive values push bright areas outward; negative values invert the effect.
  • Midlevel: Defines the texture gray value that produces zero displacement. The default value is 0.500.

Step 5: Refine the Final Look

  1. Right-click the object in the viewport and select Shade Smooth to hide sharp faces.
  2. For higher surface quality, add a Subdivision Surface modifier. Placing it above the Displace modifier in the modifier stack increases resolution before displacement; placing it below smooths the deformed results.
