What is Affect Only Origins in Blender?

The "Affect Only Origins" option in Blender is a transform tool setting that allows you to move, rotate, or scale an object's origin point independently without altering the position or shape of its underlying geometry. This article covers what an object origin is, how the "Affect Only Origins" setting functions, step-by-step instructions on how to enable it, and the practical scenarios where it is essential for 3D modeling, rigging, and animation.

Understanding the Object Origin in Blender

Every object in Blender has an origin point, represented visually by a small orange dot. The origin serves as the anchor point for the object's local coordinate system.

When you perform transform operations—such as translating (G), rotating (R), or scaling (S)—the object rotates around, scales from, or moves relative to this origin point. By default, transforming an object moves both its geometry and its origin point together.

How "Affect Only Origins" Works

When you activate Affect Only Origins, Blender isolates the origin point from the mesh.

  • Translation (Move): Moving the object changes the origin's location in 3D space, while the mesh remains fixed in place.
  • Rotation: Rotating changes the orientation of the object’s local axes without changing the direction the mesh faces.
  • Scaling: Scaling adjusts the distance between multiple object origins when selecting multiple objects, or shifts the relative scale values of the local space.

This feature eliminates the need to manually move geometry in Edit Mode or use complex 3D Cursor workflows just to adjust where an object's pivot point rests.

How to Enable "Affect Only Origins"

You can toggle this option on or off using either the graphical interface or a keyboard shortcut:

Method 1: Using the 3D Viewport Header

  1. Look at the top-right area of the 3D Viewport.
  2. Click on the Options dropdown menu.
  3. Under the Transform section, check the box labeled Origins (under "Affect Only").

Method 2: Keyboard Shortcut

  • Press Ctrl + . (Control + Period) on your keyboard to quickly toggle the setting on and off.

Note: Remember to disable the setting once you finish adjusting your origin point, as leaving it on will prevent you from moving your actual objects.

Practical Use Cases

1. Setting Door Hinges and Mechanical Pivots

To make a door swing open correctly, the origin point must sit on the hinge axis rather than the center of the door frame. Enabling "Affect Only Origins" allows you to slide the origin directly to the edge of the door mesh.

2. Preparing Assets for Game Engines

Game engines like Unreal Engine and Unity rely on an object's origin point as its primary placement handle. Setting the origin to the bottom center of a prop (like a tree or a chair) ensures it snaps cleanly to floors when placed in a game environment.

3. Aligning Local Axes

If an object was rotated in Object Mode and its local alignment is off, you can rotate only the origin to realign the object's local X, Y, and Z axes to align perfectly with specific geometry or world directions.

4. Working with Modifiers

Certain modifiers, such as the Array Modifier using an Object Offset or the Mirror Modifier, rely heavily on the origin's location and rotation. Adjusting the origin allows you to fine-tune how array copies scatter or where a mesh mirrors without moving the base mesh itself.
