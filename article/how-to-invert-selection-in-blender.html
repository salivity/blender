How to Invert Selection in Blender

Inverting your selection in Blender allows you to instantly deselect everything currently highlighted and select all unselected elements instead. This article provides a quick guide on how to invert selections in Blender using keyboard shortcuts and menu commands across various modes, including Object Mode, Edit Mode, and Node Editors.

The Keyboard Shortcut

The fastest way to invert your selection anywhere in Blender is using the dedicated keyboard shortcut:

  • Windows / Linux: Press Ctrl + I
  • macOS: Press Cmd + I

Simply select the items, vertices, edges, or faces you want to exclude, press the shortcut, and Blender will swap the active selection.

Inverting Selection via the Header Menu

If you prefer using the graphical user interface, you can access the invert function through the top menu bar of your active viewport:

  1. Look at the top-left corner of the 3D Viewport.
  2. Click on the Select menu.
  3. Choose Invert from the drop-down list.

Usage in Different Modes

The invert command works contextually depending on the mode you are currently using:

  • Object Mode: Inverts the selection of entire 3D objects within the scene.
  • Edit Mode: Inverts the selection of mesh components (vertices, edges, or faces) depending on your current selection mode.
  • Node Editors (Shader, Geometry, Compositor): Inverts the selection of active nodes.
  • UV Editor / Image Editor: Inverts the selection of UV vertices or faces.
