How to Create a Checker Pattern in Blender

Creating a checker pattern in Blender is a simple process using the Checker Texture node inside the Shader Editor. This guide explains how to add the Checker Texture node to an object's material, connect it properly to control base colors, adjust its scale, and use texture coordinate mapping to precise align the pattern on your 3D models.

Step 1: Set Up the Shader Editor

  1. Select the object you want to apply the pattern to in the 3D Viewport.
  2. Switch to the Shading workspace at the top of the screen, or open a Shader Editor window.
  3. Click New at the top of the Shader Editor to assign a new material to your object.

Step 2: Add the Checker Texture Node

  1. Press Shift + A inside the Shader Editor window to open the Add menu.
  2. Navigate to Texture and select Checker Texture.
  3. Place the node to the left of your default Principled BSDF shader node.

Step 3: Connect the Nodes

  1. Click and drag the Color output socket of the Checker Texture node.
  2. Connect it to the Base Color input socket of the Principled BSDF node.
  3. The surface of your object in the viewport will immediately display a 2D checkerboard grid.

Step 4: Customize the Pattern Settings

The Checker Texture node includes built-in parameters to modify the appearance:

  • Color1 & Color2: Click these color swatches to change the primary and secondary colors of the grid squares.
  • Scale: Adjust this value to control the size and frequency of the checker squares. Higher numbers result in smaller, more numerous squares.

Step 5: Adjust Mapping and Alignment

To control how the pattern wraps around your object's geometry, use texture mapping nodes:

  1. Select the Checker Texture node.
  2. If you have the Node Wrangler add-on enabled (built into Blender), press Ctrl + T to automatically add a Texture Coordinate node and a Mapping node.
  3. Alternatively, manually add a Texture Coordinate node (Shift + A > Input > Texture Coordinate) and a Mapping node (Shift + A > Vector > Mapping).
  4. Connect the UV (for UV unwrapped meshes) or Generated output of the Texture Coordinate node to the Vector input of the Mapping node.
  5. Connect the Vector output of the Mapping node to the Vector input of the Checker Texture node.
  6. Adjust the Scale, Location, and Rotation settings inside the Mapping node to stretch, move, or rotate the grid across your object.
