Mesh Boolean Node in Blender Geometry Nodes

The Mesh Boolean node is a fundamental tool within Blender's Geometry Nodes system used to procedurally cut, combine, or intersect 3D geometry. This article explains how the Mesh Boolean node functions, breaks down its core operations and solver types, and covers best practices for integrating it into non-destructive procedural modeling workflows.

What Is the Mesh Boolean Node?

The Mesh Boolean node performs constructive solid geometry (CSG) operations on mesh data directly inside Geometry Nodes. Instead of applying a traditional destructive Boolean modifier to an object, this node allows you to dynamically subtract, add, or isolate overlapping volumes within a node tree.

Boolean Operations

The node provides three primary operations to dictate how the input meshes interact:

  • Intersect: Keeps only the overlapping volume shared by both input meshes, discarding all non-intersecting geometry.
  • Union: Merges the two meshes into a single continuous surface, automatically removing any internal, overlapping geometry.
  • Difference: Cuts the geometry of the second input mesh out of the first input mesh, leaving behind a cavity or carved shape.

Solver Methods

The Mesh Boolean node provides two distinct calculation solvers:

  1. Exact: Uses high-precision math to handle complex geometry, coplanar faces, and overlapping edges. It is more reliable and robust but requires more computational power.
  2. Fast (Float): Uses floating-point math for quicker calculations. It is ideal for real-time performance and simple shapes, though it may produce artifacts when dealing with coplanar or non-manifold geometry.

Key Inputs and Outputs

  • Mesh 1 and Mesh 2 Inputs: The target and tool geometries that will interact.
  • Self Intersection: An option that resolves internal self-intersections within the input meshes before performing the main operation.
  • Hole Tolerances: Settings available in the Exact solver to optimize how the algorithm detects and handles micro-gaps.
  • Mesh Output: The resulting procedural geometry.
  • Intersecting Edges Output: A boolean selection attribute indicating which edges were generated by the intersection, useful for beveling, assigning materials, or scattering details along seams.

Best Practices

  • Ensure Watertight Meshes: Boolean operations work best on manifold (closed) geometry with consistent face normals. Non-manifold inputs can lead to missing faces or computation errors.
  • Optimize Polycount: Because Boolean operations can create complex n-gons and heavy geometry recalculations, use low-to-medium poly meshes when animating to maintain high viewport framerates.
  • Cleanup Topology: Combine the Mesh Boolean node with nodes like Merge by Distance or Triangulate downstream to clean up loose vertices and artifacts.
