Blender Transform Constraint for Rigging Gears

The Transformation constraint in Blender is a vital tool for rigging mechanical gear systems, enabling animators to automatically drive the movement of follower gears from a single control gear. By mapping the rotational values of a source object to a target object, this constraint automates complex intermeshing motions, maintains precise gear ratios, and ensures realistic, synchronized animations without requiring individual keyframes for every component.

Mapping Rotational Input to Output

When rigging mechanical assemblies, the primary function of the Transformation constraint is converting the rotation of a driving gear into the corresponding rotation of a driven gear. Instead of manually keyframing each gear's movement, the constraint reads the rotational angle (such as the Z-axis rotation) of the target driver and directly applies it to the constrained object.

Setting Precise Gear Ratios

Mechanical gears of different sizes must rotate at different speeds to mesh realistically. The Transformation constraint handles this through its source and destination value ranges:

  • Source Range: Defines the input rotation range of the driver gear (e.g., Min: 0°, Max: 360°).
  • Destination Range: Defines the resulting output rotation for the driven gear based on its tooth count relative to the driver.

For example, if a 20-tooth driver gear rotates a 10-tooth driven gear, the driven gear must rotate twice as fast. Setting the source to 360° and the destination to 720° achieves this exact 2:1 mechanical ratio automatically.

Inverting Direction and Changing Axes

External interlocking gears must rotate in opposite directions. The Transformation constraint accomplishes this simply by inverting the destination values (e.g., mapping a source of 360° to a destination of -360°). Furthermore, it can map rotation across different axes, making it suitable for rigging bevel gears, worm gears, and perpendicular drivetrains where rotation on the Z-axis must translate into rotation on the X or Y axis.

Workflow and Performance Benefits

Using the Transformation constraint eliminates the need to write complex Python driver expressions for simple mechanical rigs. It provides real-time viewport feedback, operates non-destructively, and allows animators to manipulate an entire mechanical system simply by animating a single master controller.
