What Does the Mix RGB Node Do in Blender?

The Mix RGB node in Blender is a versatile tool used in both the Shader Editor and Compositor to combine two color sources, textures, or image inputs based on mathematical operations and a blend factor. This article explains how the Mix RGB node functions, breaks down its core inputs and blend modes, and demonstrates practical ways to use it to control colors, create masks, and overlay texture details in your 3D projects.

Core Inputs and Outputs

The Mix RGB node operates using three main inputs to produce a single blended color output:

  • Factor (Fac): Controls how much influence the second color input (Color 2) has over the first color input (Color 1). A value of 0.0 outputs only Color 1, a value of 1.0 outputs only Color 2, and values in between blend the two. Plugging a grayscale texture or mask into the Factor input allows you to blend colors localized to specific areas of a mesh.
  • Color 1: The primary base color, texture, or image.
  • Color 2: The secondary color, texture, or image that is blended onto Color 1.
  • Color Output: The resulting blended color, which plugs into shaders, other nodes, or the final material output.

How Blending Modes Work

The dropdown menu at the top of the node determines the mathematical formula used to combine Color 1 and Color 2. Here are the most common blending modes:

  • Mix: Standard alpha blending. It smoothly transitions from Color 1 to Color 2 based on the Factor value.
  • Multiply: Multiplies the color values of Color 1 by Color 2. Because pure white is 1.0 and pure black is 0.0, white leaves colors unchanged while black turns them completely black. This is ideal for adding dirt, shadows, or ambient occlusion maps.
  • Add: Adds the color values of Color 2 to Color 1, brightening the overall result. Useful for creating glow effects or light passes.
  • Screen: The opposite of Multiply. It brightens the image while preserving highlights, making it ideal for combining light effects, lens flares, or soft overlays.
  • Overlay: Combines Multiply and Screen modes. It preserves the highlights and shadows of Color 1 while applying the midtones of Color 2, making it great for adding surface bumps or detailed patterns without changing light values.
  • Darken / Lighten: Compares the two color inputs pixel-by-pixel and keeps only the darker (Darken) or lighter (Lighten) color value.

Common Use Cases in Blender

1. Layering Textures and Imperfections

You can use a Mix RGB node set to Multiply or Overlay to apply surface imperfections, such as scratches, dust, or fingerprints, onto a clean base color texture.

2. Texture Masking

By plugging a black-and-white texture (like a Noise Texture or image mask) into the Factor input, you can paint or isolate different colors on a single material. For example, rust can be placed exclusively in the crevices of a metallic object.

3. Adjusting Texture Intensity

If a texture map is too strong, running it through a Mix RGB node allows you to mix the original texture with a solid neutral color to dial back its intensity before sending it to a material shader.
