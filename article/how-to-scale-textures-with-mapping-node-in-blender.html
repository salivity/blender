How to Scale Textures with Mapping Node in Blender

Scaling textures in Blender allows you to control how a pattern or image fits onto a 3D model. By using the Mapping node alongside a Texture Coordinate node in the Shader Editor, you can easily adjust the size, rotation, and position of any procedural or image texture. This guide provides a direct, step-by-step walkthrough for setting up these nodes and tweaking the Scale values to achieve your desired material look.

Step 1: Set Up the Shader Editor

  1. Select the object you want to texturize in your 3D Viewport.
  2. Switch to the Shading workspace, or open a Shader Editor window.
  3. Ensure your object has a material assigned to it.

Step 2: Add the Required Nodes

To adjust scaling, you need both a Mapping node and a Texture Coordinate node.

  1. Press Shift + A in the Shader Editor.
  2. Search for and add a Texture Coordinate node.
  3. Press Shift + A again, then search for and add a Mapping node.
  4. Place these nodes to the left of your Image Texture or Procedural Texture (such as Noise or Voronoi) node.

Note: If you have the built-in Node Wrangler add-on enabled, select your texture node and press Ctrl + T to automatically generate and connect both nodes.

Step 3: Connect the Node Pipeline

Connect the nodes in this specific sequence:

  1. Drag a line from the UV output (or Generated output) of the Texture Coordinate node into the Vector input of the Mapping node.
  2. Drag a line from the Vector output of the Mapping node into the Vector input of your Texture node.
  3. Ensure your Texture node's Color output connects to the Base Color of your Principled BSDF shader node.

Step 4: Adjust the Scale Input

Locate the Scale section on the Mapping node, which contains X, Y, and Z value fields:

  • To make the texture smaller (more repetitions/tiling): Increase the Scale values (e.g., set X, Y, and Z to 2.0 or higher).
  • To make the texture larger (zoomed in): Decrease the Scale values (e.g., set X, Y, and Z to 0.5 or lower).
  • Uniform Scaling: Left-click and drag down across the X, Y, and Z fields on the Mapping node to select all three at once, then type a number to scale the texture evenly in all dimensions.
  • Non-Uniform Scaling: Change individual axis values independently to stretch or compress the texture along a specific direction.
