How to Move an Object Along Local Axis in Blender

Moving an object along its local axis in Blender allows you to translate it relative to its own orientation rather than the global world grid. This guide explains how to switch to local transformation modes using quick keyboard shortcuts, the Transform Orientation menu, and the interactive Move Gizmo for precise object manipulation.

Method 1: Using Keyboard Shortcuts (Fastest)

The quickest way to move an object along its local axis is by pressing the axis key twice during a transformation command.

  1. Select the object in the 3D Viewport.
  2. Press G to initiate the Move (Grab) tool.
  3. Press the desired axis key twice (X, Y, or Z):
    • Press G then X then X to lock movement to the Local X-axis.
    • Press G then Y then Y to lock movement to the Local Y-axis.
    • Press G then Z then Z to lock movement to the Local Z-axis.
  4. Move your mouse to position the object, then Left-Click or press Enter to confirm.

Method 2: Changing the Global Orientation to Local

If you need to perform multiple local movements, you can set the default orientation for the viewport to Local.

  1. Locate the Transform Orientation drop-down menu at the top center of the 3D Viewport (it defaults to "Global").
  2. Click the drop-down menu and select Local.
  3. Select your object and press G, followed by a single axis key (X, Y, or Z). Blender will now default to moving along the chosen local axis.

Method 3: Using the Move Gizmo

For visual control over object placement, use the interactive transform handles.

  1. Select the Move Tool from the toolbar on the left side of the 3D Viewport (or press Shift + Spacebar then G).
  2. Set the Transform Orientation menu at the top of the screen to Local.
  3. Click and drag the colored arrows on the object:
    • Red Arrow: Local X-axis
    • Green Arrow: Local Y-axis
    • Blue Arrow: Local Z-axis
