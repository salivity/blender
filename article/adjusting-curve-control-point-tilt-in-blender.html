Adjusting Curve Control Point Tilt in Blender

In Blender, the tilt property of a curve control point determines the local axial rotation—or twist—of the curve profile around its direction vector at that specific point. This property is essential when working with extruded or beveled curves, such as cables, pipes, ribbons, and camera paths, where precise control over the orientation and twisting of the geometry is required. This guide explains what the 3D tilt property does and outlines the various methods to adjust, view, and reset it in Blender.

What is the Tilt Property?

Every control point on a 3D curve possesses a tilt angle. While location coordinates (X, Y, Z) dictate the path of the curve and handle vectors control the curvature, the tilt value dictates how a 2D bevel shape or extrusion twists as it passes through each point.

Without tilt adjustments, Blender calculates twisting automatically based on the curve's global settings. Adjusting the tilt manually allows you to override default twisting, enabling you to bank turns on roller coasters, align flat geometry to surfaces, or create twisted braided cables.

How to Adjust Tilt in Edit Mode

To adjust the tilt of a curve, ensure your curve is in Edit Mode (Tab), select one or more control points, and use one of the following methods:

1. The Interactive Keyboard Shortcut

  • Select the desired control point(s).
  • Press Ctrl + T.
  • Move your mouse to rotate the tilt interactively, or type a specific angle value (e.g., 45 or -90) and press Enter.

2. The Transform Sidebar (N-Panel)

  • With your control point(s) selected, press N to open the Sidebar in the 3D Viewport.
  • Navigate to the Item tab.
  • In the Transform section, locate the Tilt field.
  • Click and drag or enter an exact numeric value in degrees.

3. The Viewport Tilt Tool

  • Press T to display the left-hand Toolbar.
  • Click and hold the Transform icons, then select the Tilt tool (or cycle through using the toolbar).
  • A specialized rotation handle will appear on the selected control point, allowing you to click and drag directly in the viewport to set the angle.

Resetting and Clearing Tilt

If you need to return the control points to their default unrotated state:

  • Select the control points in Edit Mode.
  • Press Alt + T (or go to Curve > Control Points > Clear Tilt from the top viewport menu).

Curve Twist Methods and Tilt Interpolation

How tilt transitions between two control points depends on the curve's global settings. In the Data Properties panel (the green curve icon), under the Shape section, you can change the Twist Method:

  • Z-Up: Prioritizes keeping the curve aligned with the global Z-axis; useful for camera rigs and paths.
  • Minimum: Calculates the shortest rotation between points; ideal for freeform organic shapes.
  • Tangent: Calculates twisting strictly along the curve tangent; ideal for loops and complex 3D paths where standard methods cause flipping.
