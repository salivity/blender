How to Stream and Display USD Files in Blender

This guide provides a straightforward overview of how to load, display, and stream Universal Scene Description (USD) files directly inside Blender. You will learn how to use Blender’s native USD import pipeline, leverage the USD Hydra delegate for high-performance viewing, and implement real-time streaming workflows using external connectors like NVIDIA Omniverse for live collaborative pipelines.

1. Native USD Importing and Display

Blender includes built-in support for reading and rendering USD files (.usd, .usda, .usdc, and .usdz).

To load and display a USD file:

  1. Open Blender and navigate to File > Import > Universal Scene Description (.usd, .usda, .usdc, .usdz).
  2. Select your USD file in the file browser.
  3. In the right-hand import settings panel, configure the following options:
    • Scale: Adjust the unit conversion (USD typically defaults to centimeters, whereas Blender uses meters).
    • Custom Properties: Enable to retain USD metadata.
    • Materials: Choose whether to import USD Preview Surface shaders as Blender shader node networks.
    • Subdivision: Check to read USD subdivision schemes.
  4. Click Import USD.

The hierarchy and geometry will appear directly in the Outliner and 3D Viewport, where you can display it using standard Solid, Material Preview, or Rendered viewport shading modes.

2. Using Hydra Render Delegates for High-Scale USD Viewing

For large-scale scenes where standard mesh conversion causes performance bottlenecks, you can use the Blender USD Hydra Addon (available for Blender 3.5+). Hydra allows Blender to stream and view USD stages directly without fully converting them to native Blender geometry meshes.

  1. Download and enable the Hydra Render Engine add-on in Edit > Preferences > Add-ons.
  2. Switch your active render engine from Eevee/Cycles to Hydra Storm or your preferred USD delegate in the Render Properties tab.
  3. Open a USD stage to bypass Blender's native modifier stack and draw massive datasets directly to the GPU using the native USD pipeline.

3. Real-Time Streaming with the Omniverse Connector

To stream live USD updates bidirectionally between external software and Blender, use the NVIDIA Omniverse Blender Connector:

  1. Install the Omniverse Launcher and install the Blender USD Connector.
  2. Enable the connector in Blender under Edit > Preferences > Add-ons.
  3. Open the Omniverse panel in the 3D Viewport sidebar (press N).
  4. Connect to your local or cloud Nucleus Server.
  5. Open or reference a live .usd file from the server.
  6. Toggle Live Sync on. Any transformations, geometry updates, or lighting changes made in the USD file from other connected applications will stream and update inside Blender in real time.

4. Viewport Optimization for USD Scenes

To ensure smooth playback and high framerates when working with complex USD stages:

  • Object Bounding Boxes: Select heavy background USD prims and set their Viewport Display mode to Bounds under the Object Properties tab.
  • Payload Management: Use the USD import settings to selectively load or unload payloads, preventing unnecessary geometry from loading into memory.
  • Cache Playback: For animated USD sequences, utilize the Mesh Sequence Cache modifier automatically applied during import to stream vertex animations per frame from disk rather than storing raw keyframe data inside the .blend file.
