Remove Green Screen Spill in Blender Compositor

Green screen spill occurs when green light from the backdrop reflects onto the edges, hair, and clothing of a foreground subject. In Blender’s Compositor, removing this unwanted tint is essential for seamless VFX integration and photorealistic composites. This guide covers the standard methods to eliminate green spill using built-in compositor nodes, including the Color Spill node, Keying node parameters, and selective color correction techniques.

Method 1: Using the Color Spill Node

The Color Spill node is the most direct and effective tool in Blender for suppressing unwanted color cast on keyed footage.

  1. Open the Compositor: Switch to the Compositing workspace and check the Use Nodes box in the top header.
  2. Add the Node: Press Shift + A, navigate to Color, and select Color Spill. Place this node in your node tree immediately after your keying node or your image source.
  3. Configure the Spill Type:
    • Set the Spill Channel to Green.
    • Choose an Unspill Algorithm (Simple or Average).
    • Select the Limiting Channel:
      • Use Red or Blue depending on the scene's lighting.
      • Select Average if you want the green channel clamped to the average value of both the red and blue channels.
  4. Adjust Spill Factor: Tune the R/G/B scale sliders to fine-tune how aggressively the green values are suppressed without overly shifting skin tones to magenta.

Method 2: Adjusting Despill in the Keying Node

If you are using the all-in-one Keying node (Shift + A > Matte > Keying), you can handle spill removal directly inside the node itself.

  1. Locate the Despill Factor slider in the Keying node settings.
  2. Increase the Despill Factor (default is typically set to 1.0) to neutralize green light around the borders.
  3. Adjust the Despill Balance slider to balance the color compensation between red and blue. A value around 0.5 offers an equal mix, while higher or lower values shift the balance toward red or blue to match the foreground subject's natural tones.

Method 3: Targeted Despill with the Hue Correct Node

For complex shots where automatic despill nodes create harsh magenta edges or wash out blond hair, the Hue Correct node offers precise manual control.

  1. Press Shift + A and go to Color > Hue Correct.
  2. Connect your keyed image output to the Hue Correct input.
  3. Select the Saturation (S) tab.
  4. Locate the Green curve point on the graph and pull it down to selectively desaturate green frequencies while leaving other colors intact.
  5. If necessary, switch to the Hue (H) tab to subtly shift lingering yellow-green tones toward warm skin tones or the ambient background color.

Method 4: Spill Replacement with Background Light Wrap

To integrate the character realistically into a new background, replace the suppressed green spill with light from the new backdrop:

  1. Invert the matte generated by your keying process using an Invert node.
  2. Use a Dilate/Erode node set to a negative value to isolate only the outermost edge of the subject.
  3. Blur the new background image heavily using a Blur node.
  4. Mix the blurred background over the despilled edges using a Mix Color node set to Add or Screen at a low opacity to simulate environmental light wrapping.
