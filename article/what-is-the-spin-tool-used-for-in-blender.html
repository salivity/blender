What Is the Spin Tool Used for in Blender?

The Spin tool in Blender is a powerful modeling feature used to duplicate and extrude selected geometry in a circular path around a specified pivot point. It is primarily used for lathe-style modeling, bending shapes, and creating radial symmetry. By sweeping a 2D profile around an axis, artists can instantly generate complex 3D objects like vases, pipes, wheels, staircases, and curved architectural elements with high precision.

Key Uses of the Spin Tool

  • Creating Rotational Geometry: The tool acts like a digital lathe. You can draw half of a 2D outline (such as a glass, bottle, or bowl) and spin it 360 degrees to create a symmetrical 3D model.
  • Bending Tubes and Pipes: By placing the pivot point outside the selected geometry, you can extrude straight geometry into smooth 90-degree elbows, curved hoses, or circular rings.
  • Duplicating Objects in a Circle: Beyond simple extrusion, the Spin tool can duplicate disconnected objects around a central axis, making it ideal for creating clock numbers, gear teeth, or spiral staircases.

How the Spin Tool Works

  1. Set the Pivot Point: The Spin tool revolves geometry around the position of the 3D Cursor. Positioning the 3D Cursor accurately determines the center axis of your rotation.
  2. Select Geometry: In Edit Mode, select the vertices, edges, or faces you want to spin.
  3. Activate the Tool: Select the Spin tool from the Toolbar on the left side of the 3D Viewport (or press Shift + Spacebar and choose Spin).
  4. Adjust the Controls: Drag the blue arc gizmo to perform the spin, or use the Adjust Last Operation panel in the bottom-left corner to set exact values.

Important Spin Tool Settings

  • Steps: Sets the number of copies or extrusions generated along the spin path. Higher values result in smoother curves, while lower values create low-poly geometry.
  • Angle: Defines how far the geometry rotates (e.g., 360° for a full cylinder or 90° for a right-angle pipe bend).
  • Axis (X, Y, Z): Specifies the plane along which the rotation occurs.
  • Auto Merge: Automatically welds the starting and ending vertices together when spinning a full 360 degrees, preventing duplicate geometry along the seam.
