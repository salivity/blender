How to Loft NURBS Surfaces in Blender

Lofting in Blender allows you to create smooth, complex 3D surfaces by generating a continuous skin across a series of cross-sectional curve profiles. Although Blender is widely known for mesh modeling, its built-in NURBS tools offer a mathematically precise way to construct organic objects like vehicle hulls, airplane wings, and industrial product designs. This guide provides a direct, step-by-step walkthrough to successfully loft shapes using NURBS surfaces in Blender.

Step 1: Add a Base NURBS Surface Curve

  1. Open Blender and ensure you are in Object Mode.
  2. Press Shift + A to open the Add menu.
  3. Navigate to Surface and select NURBS Curve or NURBS Circle (do not use the standard “Curve” category, as standard Bezier/Path curves do not loft in the same way with surface tools).

Step 2: Create Additional Cross-Section Profiles

  1. With your initial NURBS surface object selected, press Shift + D to duplicate it.
  2. Move, scale, or rotate the duplicated profile along an axis (usually the Z-axis) to define the silhouette of your shape.
  3. Repeat this process, placing multiple profiles along the path of your intended object to define its overall volume.

Step 3: Join the Profiles Into a Single Object

  1. In Object Mode, select all the individual NURBS profiles you created.
  2. Press Ctrl + J to join them into a single unified object.

Step 4: Loft the Profiles Together

  1. Select the newly joined object and press Tab to switch to Edit Mode.
  2. Press A to select all the control points across all profiles.
  3. Press F (or go to the top menu and select Surface > Make Segment/Face).
  4. Blender will instantly generate a continuous surface skin across all of your profile sections.

Step 5: Adjust and Refine the Lofted Shape

  • Modify Geometry: Select individual control points in Edit Mode and move, scale, or rotate them to fine-tune the curvature of the lofted surface.
  • Surface Resolution: To increase or decrease the smooth quality of the model, go to the Object Data Properties tab (green curve icon) on the right panel and adjust the Resolution Preview U and V values.
  • Cap the Ends (Optional): If you need a closed shape, select the end profiles in Edit Mode and press F to close the openings.

Step 6: Convert to Mesh (Optional)

If you plan to use standard polygon editing, sculpt mode, or game engine export: 1. Switch back to Object Mode. 2. Right-click the object and choose Convert To > Mesh.
