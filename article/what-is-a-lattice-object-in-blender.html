What Is a Lattice Object in Blender?

A lattice object in Blender is a non-destructive deformation tool that uses a simple grid wireframe to manipulate the shape of complex 3D meshes, curves, or particle systems. Instead of editing thousands of individual vertices on a high-poly model, you place the object inside a lattice cage and adjust the cage’s control points to smoothly bend, stretch, or shape the enclosed geometry.

How the Lattice Object Works

A lattice consists of a three-dimensional grid defined by U, V, and W resolution axes. When linked to a target mesh using the Lattice Modifier, any transformation applied to the lattice grid directly distorts the target mesh proportional to its position inside the structure.

  • Non-Destructive Deformations: The underlying mesh topology remains completely untouched. Disabling or removing the lattice restores the original geometry instantly.
  • Low-Poly Control over High-Poly Meshes: Editing a high-resolution character or asset directly can lead to uneven surfaces. Moving a single vertex on a 3x3x3 lattice evenly distributes the deformation across thousands of target vertices.
  • Global and Local Scope: A lattice can deform an entire object, multiple objects simultaneously, or specific vertex groups for localized control.

Key Applications in 3D Workflows

1. Character Animation and Cartoon Physics

Lattices are widely used in character rigging to achieve cartoon-style “squash and stretch” effects. Parents or drivers can be attached to the lattice control points, allowing animators to exaggerate expressions or impact impacts dynamically without breaking the character’s base mesh structure.

2. Proportional Reshaping and Art Direction

When tweaking asset proportions—such as adjusting the curve of a car body, altering the silhouette of a weapon, or reshaping footwear—a lattice allows for broad, smooth adjustments. It prevents the surface pinching or distortion common with manual vertex tweaking.

3. Deforming Complex Multi-Object Assemblies

If a model consists of dozens of separate objects (such as a layered clothing system or a complex mechanical part), deforming them individually causes gaps and misalignments. By assigning all objects to the same lattice modifier, the entire assembly deforms as a single cohesive unit.

Basic Setup Process

  1. Add the Lattice: Press Shift + A and select Lattice. Scale and position the lattice box so it completely surrounds the target object.
  2. Adjust Grid Density: In the Object Data Properties tab, adjust the U, V, and W values to set the number of control points needed for the deformation.
  3. Bind to the Object: Select the target mesh, add a Lattice Modifier, and select your lattice object in the Object field.
  4. Deform: Select the lattice, enter Edit Mode, and move, scale, or rotate its control points to reshape the target geometry.
