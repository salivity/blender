What Is Realize Instances in Blender Geometry Nodes

The Realize Instances node in Blender Geometry Nodes converts virtual, duplicated instances into real, editable mesh geometry. This article explains how the node works, its primary use cases—such as applying mesh operations, deforming geometry, and exporting assets—and the performance implications of turning lightweight instance data into fully realized geometry.

Understanding Instances vs. Real Geometry

When you use nodes like Instance on Points, Blender does not duplicate actual mesh data (vertices, edges, and faces). Instead, it creates lightweight references—called instances—that point to the original base geometry. This keeps memory usage low and viewport performance high, even when scattering millions of objects.

However, because instances are merely pointers transformed in 3D space, Blender cannot interact with their individual vertices or faces directly.

What the Realize Instances Node Does

The Realize Instances node takes this instanced data and merges it into a single, cohesive mesh object. It converts every virtual copy into actual geometry with its own unique vertices, edges, faces, and UV maps.

Primary Use Cases

1. Applying Mesh Modeling Nodes

If you want to perform mesh-level operations on instanced objects, you must realize them first. This includes:

  • Mesh Boolean: Merging, subtracting, or intersecting instanced shapes.
  • Extrude Mesh: Adding depth to instanced 2D curves or faces.
  • Subdivision Surface: Smoothing the geometry of instanced objects procedurally.
  • Raycast & Proximity: Reading precise surface data from the scattered objects.

2. Exporting to Other Software

Most standard 3D file formats (such as FBX, OBJ, and USD) and external game engines (such as Unreal Engine and Unity) cannot interpret Blender's procedural instances automatically. Realizing instances before exporting ensures the entire generated scene is converted into standard mesh data recognized by other applications.

3. Using Downstream Modifiers

Standard Blender modifiers placed after the Geometry Nodes modifier stack (such as Armature, Displace, or Decimate) only evaluate real geometry. The Realize Instances node ensures the generated shapes are accessible to these modifiers.

4. Attribute and Vertex Color Baking

When generating vertex groups, custom attributes, or UV coordinates across instances, realizing the instances allows individual attribute values to be written to each vertex rather than shared globally from the source object.

Performance Considerations

While essential for specific workflows, the Realize Instances node should be used selectively. Converting millions of lightweight instances into real geometry creates millions of real polygons, which can significantly increase RAM consumption, slow down viewport frame rates, and increase render preparation times. Always apply this node as late in the node tree as possible, and avoid it entirely if simple rendering of duplicated assets is the only goal.
