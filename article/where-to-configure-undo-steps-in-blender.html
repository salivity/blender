Where to Configure Undo Steps in Blender

Configuring the number of undo steps in Blender allows you to balance your workflow flexibility with your computer's memory usage. By default, Blender saves a specific number of previous actions, but you can easily increase or decrease this limit depending on your system's hardware capabilities. This guide provides a direct, step-by-step walkthrough on how to locate and modify the undo memory settings in Blender.

Steps to Change Undo Steps in Blender

  1. Open the Preferences Menu Click on Edit in the top main menu bar and select Preferences from the dropdown menu. You can also open it using the keyboard shortcut Cmd + , on Mac or by navigating through the top bar.

  2. Navigate to the System Tab Inside the Blender Preferences window, click on the System tab located in the navigation menu on the left side.

  3. Locate Memory & Limits Look at the top section of the System settings panel to find the Memory & Limits header.

  4. Adjust the Undo Steps Value Find the field labeled Undo Steps.

    • Click and drag the slider, or click directly into the box to type a custom number.
    • The default setting is 32 steps.
    • You can set this value anywhere from 0 up to a maximum of 256 steps.

  5. Save Preferences Blender saves preference changes automatically by default. If you have auto-save disabled, click the burger menu icon (three horizontal lines) in the bottom-left corner of the Preferences window and click Save Preferences.

Important Details to Keep in Mind

  • RAM Usage: Higher undo step counts require more system RAM. If you work on complex scenes with high polygon counts or heavy simulations, setting the undo limit too high may slow down performance or cause high memory consumption.
  • Global Undo: Make sure the Global Undo checkbox adjacent to the Undo Steps field remains enabled. Disabling this option prevents Blender from saving your action history when switching between different interaction modes (such as Object Mode and Edit Mode).
