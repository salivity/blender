How to Cap the Ends of an Array in Blender

Capping the ends of an array in Blender allows you to automatically seal or finish the open ends of a duplicated mesh without manually editing geometry. This is achieved natively using the Caps feature inside the Array Modifier, where separate mesh objects are assigned to act as the start and end pieces of the array sequence non-destructively.

Step-by-Step Guide to Capping an Array

1. Prepare Your Base and Cap Meshes

  1. Create your main repeating object (e.g., a fence segment or chain link).
  2. Create a separate mesh object that will serve as the cap (e.g., a fence post or decorative end piece).
  3. Ensure the origins of both objects are aligned properly so the cap seamlessly meets the main geometry.

2. Apply the Array Modifier

  1. Select your main object.
  2. Go to the Modifier Properties tab (wrench icon) in the Sidebar.
  3. Click Add Modifier and select Array.
  4. Set the Count and adjust the Relative Offset or Constant Offset to space your repeating elements correctly.

3. Assign the Caps

  1. In the Array Modifier settings, locate and expand the Caps drop-down section.
  2. Click the Start Cap eyedropper or search field and select your cap object.
  3. Click the End Cap eyedropper or search field and select the cap object (or a different object if you want distinct start and end caps).

4. Merge Vertices (Optional)

If your cap geometry shares matching boundary vertices with the main array object:

  1. Check the Merge box inside the Array Modifier.
  2. Adjust the Distance threshold if needed so touching vertices fuse together automatically.
