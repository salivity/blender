What Is Grease Pencil Draw Mode in Blender?

Blender's Grease Pencil Draw Mode is a specialized workspace that allows artists to sketch, illustrate, and animate traditional 2D art directly within a 3D environment. This article covers what Draw Mode is, its essential tools, how it functions within the 3D viewport, and how it bridges the gap between 2D illustration and 3D modeling.

Grease Pencil is a unique object type in Blender, and Draw Mode is the default mode used for creating its strokes. When active, it transforms the 3D viewport into a digital drawing canvas, allowing freehand strokes to be projected in 3D space, on flat planes, or directly onto the surfaces of 3D geometry.

Key Features of Draw Mode

  • Specialized Brushes: Draw Mode provides access to a dedicated brush system, including pencils, pens, inkers, markers, and airbrushes. These brushes support drawing tablet pressure sensitivity for dynamic line weight, opacity, and jitter control.
  • Stroke and Fill Materials: Unlike standard 3D meshes that use surface shaders, Grease Pencil uses materials configured for line strokes, solid fills, gradients, or textures. You can draw outlines and filled shapes simultaneously or on separate passes.
  • Stroke Placement Options: Artists can control where strokes appear in 3D space using the Stroke Placement settings:
    • Origin: Draws on the object's local center plane.
    • 3D Cursor: Draws aligned to the current position of the 3D cursor.
    • Surface: Projects strokes directly onto the visible faces of other 3D objects in the scene.
    • Stroke: Snaps new lines directly onto previously drawn Grease Pencil strokes.
  • Drawing Guides and Stabilization: Draw Mode includes built-in drawing aids such as circular, radial, grid, and parallel guides, as well as stroke stabilization settings to ensure clean, steady line work.

How to Access Draw Mode

  1. Open Blender and press Shift + A in the 3D Viewport.
  2. Navigate to Grease Pencil and select a preset, such as Blank, Stroke, or Monkey.
  3. Select the Grease Pencil object and switch the mode dropdown in the top-left corner of the viewport from Object Mode to Draw Mode (or press Ctrl + Tab and select Draw).

Common Use Cases

  • 2D Animation: Creating frame-by-frame, hand-drawn animations with onion skinning support in a 3D coordinate system.
  • Storyboarding and Concept Art: Rapidly sketching scenes, composition layouts, and character concepts directly in a shared virtual space.
  • 3D Annotations: Reviewing 3D models or animations by sketching notes and corrective lines directly over geometry.
  • Hybrid 2D/3D Art: Combining flat, stylized 2D characters with dynamic 3D backgrounds and camera movements.
