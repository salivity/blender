How to Organize Assets into Catalogs in Blender

Blender's Asset Browser allows you to efficiently manage 3D models, materials, node groups, and poses using a directory-like catalog system. This guide provides a direct, step-by-step walkthrough on how to create catalogs, set up nested sub-catalogs, assign assets, and save catalog definitions to maintain a structured 3D production library.

1. Open the Asset Browser

  1. Split an existing area or change a workspace editor to the Asset Browser via the Editor Type menu in the top-left corner of any window.
  2. In the top-left dropdown of the Asset Browser, select Current File (or your designated custom Asset Library).

2. Create and Rename Catalogs

  1. If the left-hand sidebar is hidden, click the arrow icon in the top-left corner or press the T key while hovering over the Asset Browser.
  2. Locate the All item at the top of the sidebar.
  3. Click the + (plus) icon next to All or right-click within the blank space and select New Catalog.
  4. Double-click the newly generated catalog name (defaults to "Catalog") to type a custom name (e.g., Props, Environments, Materials), then press Enter.

3. Create Sub-Catalogs (Nesting)

  1. Hover over an existing catalog in the sidebar.
  2. Click the + icon immediately next to that catalog's name to generate a child catalog inside it.
  3. Alternatively, drag and drop one existing catalog onto another to nest it hierarchically (e.g., Props > Furniture > Chairs).

4. Assign Assets to Catalogs

  1. Ensure your objects, materials, or collections are marked as assets (Right-click item in Outliner or Shader Editor > Mark as Asset).
  2. Click All or Unassigned in the sidebar to view all available assets in the preview grid.
  3. Left-click to select an asset, or hold Shift / Box Select (B) to select multiple assets.
  4. Drag and drop the selected items from the preview area onto the target catalog name in the left sidebar.

5. Save the Catalog Definitions

  • Catalogs are virtual tags stored in a text file named blender_assets.cats.txt located in the directory of your asset library.
  • When catalog edits are made, a Save Catalogs button will appear in the Asset Browser header with an asterisk (*). Click Save Catalogs or press Ctrl + S while saving your .blend file to write the changes to disk.

6. Managing and Deleting Catalogs

  • Rename: Double-click the catalog or right-click and choose Rename Catalog.
  • Delete: Right-click the catalog and choose Delete Catalog. Deleting a catalog does not delete the 3D assets; it merely removes the catalog tag and moves the assets back to the Unassigned list.
