Blender Dynamic Paint Canvas and Brush Guide

Blender's Dynamic Paint is a versatile physics modifier system that turns 3D objects into interactive canvases and brushes to generate dynamic textures, vertex colors, displacements, and wave simulations. This guide explains how the Canvas and Brush components interact, details the primary surface types and brush settings, and provides practical use cases for integrating Dynamic Paint into your 3D workflow.

The Core Concept: Canvas vs. Brush

The Dynamic Paint system relies on two main components:

  • Canvas: The object that receives the paint, deformation, or simulation data. It acts as the surface being altered.
  • Brush: The object that applies the paint, force, or deformation onto the Canvas based on its proximity, movement, or mesh volume.

When a Brush enters the influence area of a Canvas during animation playback, the Canvas records the interaction based on your defined settings.

The Canvas: Surface Types and Output Formats

A single Canvas can hold multiple independent surface layers. The most critical setting for a Canvas is its Surface Type, which determines how the surface reacts:

  • Paint: Generates color maps or wet maps. Ideal for painting trails, blood splatters, or drying surfaces.
  • Displace: Displaces the mesh geometry dynamically based on brush contact, creating indentations or raised geometry.
  • Waves: Generates realistic water ripples and wave dynamics upon contact with the brush.
  • Weight: Generates vertex weight groups dynamically, which can control particle distribution, modifiers, or material blending in real time.

Canvas Output Formats

The Canvas can output data in two primary ways:

  1. Vertex: Applies changes directly to the mesh's vertex colors, vertex groups, or geometry. This requires high mesh resolution for detailed results.
  2. Image Sequence: Bakes the simulation data into a sequence of UV image textures. This is resolution-independent from the mesh geometry and works well for low-poly meshes.

The Brush: Sources and Influence

The Brush defines how the interacting object impacts the Canvas.

Paint Source

The Paint Source determines what part of the brush applies the effect:

  • Mesh Volume: Paints only where the brush mesh physically intersects the canvas.
  • Proximity: Paints based on the distance between the brush and canvas, even if they do not touch.
  • Mesh Volume + Proximity: Combines both intersection and distance falloff.
  • Particle System: Uses an attached particle system instead of the mesh geometry to paint on the canvas.

Key Brush Parameters

  • Paint Color & Alpha: Controls the color and opacity applied to the Canvas.
  • Wetness: Dictates how wet the paint is, enabling secondary effects like paint dripping or smudging.
  • Absolute Alpha: Prevents paint from building up beyond the brush's set alpha value.
  • Velocity: Allows the speed and direction of the brush to influence wave generation or paint scattering.

Practical Applications

  1. Footprints and Tire Tracks: Set the ground as a Canvas with the surface type set to Displace or Weight, and the character's feet or vehicle tires as the Brush to leave indentations in snow, sand, or mud.
  2. Dynamic Water Ripple Effects: Set a water plane as a Canvas with Waves, and any floating or falling object as a Brush to generate realistic ripples on impact.
  3. Dynamic Material Masks: Use the Canvas with Weight or Paint to generate a mask that reveals a damaged or wet shader underneath as an object scrapes or touches the surface.
  4. Raindrops and Splashes: Use a particle system emitting rain droplets as a Brush over a ground Canvas to create wet maps or surface ripples.

Basic Setup Workflow

  1. Select the receiver mesh, go to the Physics Properties tab, click Dynamic Paint, set the type to Canvas, and click Add Canvas.
  2. Choose the desired Surface Type (e.g., Paint, Displace, or Waves).
  3. Select the interacting mesh, add Dynamic Paint, set the type to Brush, and click Add Brush.
  4. Set the Paint Source (e.g., Mesh Volume).
  5. Play the animation timeline to see real-time interaction, or use the Canvas Bake settings to cache the simulation for final rendering.
