How to Select an Edge Ring in Blender

Selecting an edge ring in Blender allows 3D artists to quickly highlight a series of parallel edges across a polygon mesh, streamlining the modeling, texturing, and geometry editing processes. This guide provides the direct keyboard shortcuts, top-menu navigation steps, and essential techniques required to select single or multiple edge rings efficiently in Blender's Edit Mode.

The Mouse and Keyboard Shortcut (Fastest Method)

  1. Press Tab to enter Edit Mode.
  2. Press 2 on your keyboard (not the Numpad) to switch to Edge Select Mode.
  3. Hold Ctrl + Alt and Left-Click on any edge that is part of the ring you want to select. (Mac users: Hold Cmd + Option and Left-Click).

Blender will instantly select all parallel edges connected in that ring sequence.

Using the Top Menu Navigation

If you prefer using the graphical user interface instead of keyboard shortcuts:

  1. Enter Edit Mode (Tab) and switch to Edge Select Mode (2).
  2. Click on a single edge to select it.
  3. In the top-left corner of the 3D Viewport, click Select.
  4. Hover over Select Loops and click Edge Rings.

How to Select Multiple Edge Rings

To select more than one edge ring at a time:

  • Hold Shift + Ctrl + Alt and Left-Click an edge on an unselected ring. This adds the new ring to your current selection without deselecting the previous one.

Edge Ring vs. Edge Loop

  • Edge Ring: Selects edges that are parallel to each other across a face loop.
  • Edge Loop: Selects edges that are connected end-to-end in a continuous line. (Shortcut: Alt + Left-Click).
