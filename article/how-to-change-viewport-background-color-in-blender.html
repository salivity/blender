How to Change Viewport Background Color in Blender

Changing the 3D viewport background color in Blender allows you to customize your workspace, reduce eye strain, and improve visibility while modeling. This guide provides quick, step-by-step instructions on how to alter the background color permanently through user preferences or temporarily for specific rendering modes.

Changing the Background Color via Preferences

To change the default viewport background color across all your projects, modify Blender's theme settings:

  1. Click Edit in the top menu bar and select Preferences.
  2. Select the Themes tab from the left sidebar.
  3. Click on 3D Viewport to expand its options.
  4. Scroll down and expand the Theme Space section.
  5. Locate the Gradient Color settings (or Theme Background depending on your background type setting).
  6. Click the color swatch next to High/Off (the top gradient color) or Low (the bottom gradient color) and select your preferred color using the color picker.
  7. To keep these changes every time you open Blender, click the Hamburger menu (three horizontal lines) in the bottom-left corner of the Preferences window and click Save Preferences.

Switching Between Solid and Gradient Backgrounds

If you want a solid color instead of a gradient:

  1. In the same Theme Space menu, find the Viewport Background dropdown or gradient settings.
  2. Adjust both gradient color swatches to the exact same color code for a completely flat, single-color background.

Changing the Rendered Viewport Background

If you are using Rendered Shading Mode and want to change the background color of your scene environment:

  1. Select the World Properties tab in the Properties panel on the right side of the screen (represented by a red globe icon).
  2. Under the Surface section, click the color box next to Color.
  3. Choose your desired background color. This color will reflect in the rendered view and final image renders unless transparent background options are enabled.
