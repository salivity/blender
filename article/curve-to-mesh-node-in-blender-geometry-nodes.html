Curve to Mesh Node in Blender Geometry Nodes

The Curve to Mesh node in Blender Geometry Nodes converts one-dimensional spline data into renderable three-dimensional mesh geometry by sweeping a profile shape along a guide curve. This node is fundamental for procedural modeling, enabling artists to create objects such as wires, pipes, roads, and foliage directly from curve inputs. Understanding its inputs, settings, and behavior allows for precise control over the topology, dimensions, and shape of generated meshes.

Core Functionality

Curves in Blender consist of vector points and control handles that define a trajectory without inherent surface geometry. The Curve to Mesh node generates polygonal faces along this trajectory. It takes the original curve as a guide path and extrudes a cross-section along its entire length to form a continuous mesh surface.

Key Inputs and Settings

  • Curve: The primary input that provides the trajectory (guide path) for the extrusion. This can be generated procedurally via primitive curve nodes or derived from existing curve objects.
  • Profile Curve: An optional secondary curve that defines the cross-sectional shape extruded along the main curve. If left empty, the node converts the curve points directly into a mesh edge chain with no thickness.
  • Fill Caps: A toggle option that creates polygonal faces at the start and end endpoints of open curves, sealing the geometry to create a closed, solid mesh.

Common Profile Shapes

The shape of the final mesh depends heavily on the curve connected to the Profile Curve socket:

  • Curve Circle: Creates cylindrical shapes such as cables, tubes, ropes, and tentacles.
  • Curve Line: Generates flat, ribbon-like surfaces suitable for roads, pathways, or tape.
  • Quadrilateral / Rectangle: Produces square or rectangular cross-sections ideal for architectural beams, planks, and rails.
  • Custom Curves: Custom spline shapes allow the generation of complex moldings, trim, and stylized geometry.

Primary Use Cases

  • Procedural Cabling and Pipes: Combining a Curve Line or Bezier Segment with a Curve Circle profile instantly generates industrial pipes or electrical wires that dynamically adjust when the curve points move.
  • Pathways and Tracks: Sweeping a flat profile along terrain-conforming curves creates procedural roads, railway tracks, and bridges.
  • Organic Elements: Using the node in combination with the Set Curve Radius node allows the thickness to taper along the curve length, making it ideal for plant stems, vines, tree branches, and hair strands.
  • Text Extrusions and Borders: Enhances 2D curve outlines or text data with custom bevels and 3D borders.

Why the Node Is Essential

Meshes generated by the Curve to Mesh node support standard mesh operations that native curves do not, such as Boolean operations, subdivision surface modifiers, UV unwrapping, and face-based shader interactions. It acts as the primary bridge between procedural curve manipulation and final render-ready mesh geometry in Blender's procedural workflow.
