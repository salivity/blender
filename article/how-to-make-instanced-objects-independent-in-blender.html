How to Make Instanced Objects Independent in Blender

In Blender, linked duplicates (instanced objects) share the same underlying mesh data, meaning any edit made to one object instantly updates all instances. To modify an instanced object separately without affecting the others, you must make it independent by converting it into a single-user object. This guide covers the quickest and most effective methods to decouple object data, materials, and animations in Blender.

Method 1: Using the "Make Single User" Menu (Fastest for Multiple Objects)

This method allows you to break the link for one or multiple selected objects simultaneously using a quick menu or keyboard shortcut.

  1. Select the instanced object (or multiple objects) in the 3D Viewport.
  2. Press U on your keyboard to open the Make Single User menu. (Alternatively, go to the top menu bar and select Object > Relations > Make Single User).
  3. Choose Object & Data.
  4. Select whether to apply this to Selected Objects or All. Choosing Selected Objects ensures only your current selection becomes unique.

Once completed, the selected object will have its own independent mesh data, allowing you to edit its vertices, edges, and faces in Edit Mode without altering the original.

Method 2: Using the Object Data Properties Tab (Best for Single Objects)

If you only want to make a single object unique, you can quickly decouple it through the Data Properties panel.

  1. Select the instanced object.
  2. In the Properties Editor on the right, click the Object Data Properties tab (represented by a green triangle icon).
  3. Next to the mesh name field, you will see a button displaying a number. This number indicates how many objects currently share this mesh data.
  4. Click the number icon.

Clicking the number automatically creates a duplicate copy of the mesh data and assigns it solely to the selected object.

How to Make Materials Independent

Unlinking an object's mesh data does not automatically unlink its material. If you change the material color on an independent object, other objects sharing that material will still change. To make a material independent:

  1. Select the object.
  2. Go to the Material Properties tab (represented by a pink sphere icon).
  3. Look next to the material name field for the number icon indicating shared users.
  4. Click the number icon to make the material unique to that object.

Preventing Instances During Creation

To avoid creating instanced objects in the future:

  • Use Shift + D to duplicate objects. This creates a fully independent duplicate.
  • Avoid using Alt + D, which creates a Linked Duplicate that shares object data by default.
