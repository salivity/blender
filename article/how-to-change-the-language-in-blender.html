How to Change the Language in Blender

Changing the interface language in Blender allows users to navigate the software in their preferred language. This guide provides a straightforward, step-by-step process for modifying Blender's display language, customizing translation options for tooltips and interface elements, and saving your preferences for future use.

Step-by-Step Guide to Changing Blender's Language

  1. Open Preferences Launch Blender. In the top-left menu bar, click on Edit and select Preferences.

  2. Navigate to the Interface Section In the Preferences window that appears, click on the Interface tab located on the left side menu.

  3. Enable Translation Scroll down to find the Translation panel. Check the box next to Translation to activate multi-language support.

  4. Select Your Preferred Language Click on the Language dropdown menu and select your chosen language from the list. The Blender interface will update immediately.

  5. Customize Translation Targets Under the Language menu, toggle the specific elements you want translated:

    • Tooltips: Translates the pop-up text descriptions that appear when hovering over tools and buttons.
    • Interface: Translates all menus, buttons, panels, and text throughout the workspace.
    • New Data: Translates the default names of newly created objects, materials, and collections.

  6. Save Your Settings Blender automatically saves preference changes by default. If auto-save is disabled, click the menu icon (three horizontal lines) in the bottom-left corner of the Preferences window and click Save Preferences.
