Animate Displacement Waves Using Dynamic Paint in Blender

Blender’s Dynamic Paint system allows you to create interactive, physics-based wave ripples by treating one object as a dynamic canvas and another as a brush. This guide explains how to configure a subdivided plane to generate real-time animated displacement waves whenever an interacting object moves through or collides with its surface, bypassing the need for complex fluid simulations.

Step 1: Prepare the Scene Geometry

  1. Open Blender and delete the default cube.
  2. Add a plane to serve as the fluid surface (Shift + A > Mesh > Plane). Scale it up to your desired dimensions.
  3. Switch to Edit Mode (Tab), right-click the plane, select Subdivide, and increase the number of cuts to at least 50–100. High vertex density is necessary for smooth wave displacement. Return to Object Mode.
  4. Add a secondary mesh object, such as a UV Sphere (Shift + A > Mesh > UV Sphere), to act as the colliding object (the brush). Position it so it intersects the plane.

Step 2: Configure the Canvas

  1. Select the subdivided plane and navigate to the Physics Properties tab in the Properties panel.
  2. Click on Dynamic Paint.
  3. Under the Type dropdown, ensure Canvas is selected, then click Add Canvas.
  4. Change the Surface Type setting from Paint to Waves.

Step 3: Configure the Brush

  1. Select the colliding sphere.
  2. In the Physics Properties tab, click Dynamic Paint.
  3. Set the Type dropdown to Brush, then click Add Brush.
  4. Leave the default settings for the brush source (Mesh Volume + Proximity or Mesh Volume).

Step 4: Animate and Test the Interaction

  1. Insert keyframes on the sphere (I > Location) across your timeline to make it pass across or bounce on the surface of the plane.
  2. Press the Spacebar to play the timeline. The plane will automatically generate dynamic ripple waves emanating from the points where the sphere touches the geometry.

Step 5: Fine-Tune Wave Physics Settings

Select the plane and adjust the following parameters in the Canvas physics settings to refine the wave behavior:

  • Damping: Controls how quickly waves lose energy and flatten out. Higher values stop ripples faster.
  • Speed: Governs how fast ripples propagate across the mesh.
  • Timescale: Adjusts the simulation speed relative to scene time.
  • Spring: Adjusts the surface tension; lower values make the surface feel more liquid, while higher values create tighter, more elastic ripples.
  • Smoothness: Blurs the wave displacement to reduce visual stepping on lower-resolution meshes.

Step 6: Enhance Visual Quality and Bake

  1. With the plane selected, add a Subdivision Surface modifier below the Dynamic Paint modifier in the Modifier stack to smooth out the final rendered geometry.
  2. Right-click the plane and select Shade Smooth.
  3. To ensure stable playback and rendering, open the Dynamic Paint > Cache section in the Canvas physics panel and click Bake.
