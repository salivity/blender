How to Expose Geometry Node Inputs in Blender

Exposing custom parameters to the Modifier panel in Blender allows you to control Geometry Nodes setups without opening the node editor. By routing internal node values to the Group Input node, you can create interactive, customizable controls—such as sliders, toggles, object pickers, and color fields—directly within the standard Modifier Properties tab.

1. Connect Values to the Group Input Node

  1. Open the Geometry Node Editor and select your object.
  2. Locate the Group Input node in your node graph.
  3. Click and drag from any input socket of a node (such as Radius, Count, Offset, or Seed) to the empty socket labeled with a + on the Group Input node.
  4. Once connected, the parameter instantly appears in the object's Modifier Properties panel.

2. Configure Parameter Settings in the Sidebar

To refine how the parameter looks and behaves in the Modifier panel, use the node editor sidebar:

  1. Press N inside the Geometry Node Editor to open the sidebar.
  2. Go to the Group tab.
  3. Under the Inputs list, select the parameter you just created.
  4. Adjust the following settings:
    • Name: Rename the input to a descriptive label (e.g., "Pillar Height" instead of "Value").
    • Type: Set or change the socket type (Float, Integer, Vector, Boolean, Object, Material, Color, etc.).
    • Default: Define the starting value when the modifier is added to a new object.
    • Min / Max (Soft/Hard): Set boundaries for sliders to prevent users from entering invalid or extreme values.
    • Tooltip: Add a description that appears when hovering over the property in the Modifier panel.

3. Add and Manage Sockets Manually

You can also create parameters before wiring them to specific nodes:

  1. In the Group tab of the N panel, click the + button above the Inputs list.
  2. Choose the desired data type for the new socket.
  3. Configure the name and default limits.
  4. Drag a wire from the newly created socket on the Group Input node to the target nodes in your graph.
  5. Use the up and down arrow buttons in the Inputs list to reorder how the properties are stacked in the Modifier panel.

4. Access the Custom Controls

Switch to the Properties Editor on the main layout and select the Modifier Properties tab (wrench icon). Your custom controls are now available in the Geometry Nodes modifier block, allowing dynamic adjustments to your procedural geometry.
