Blender Keying Node for Green Screen Removal

This article provides an overview of the Keying node in Blender's Compositor, explaining its primary role in visual effects and green-screen removal (chroma keying). You will learn what the node does, its key internal processes—including matte generation and despill correction—and why it serves as an essential all-in-one tool for isolating subjects and integrating them into new backgrounds.

What Is the Keying Node?

The Keying node is a dedicated chroma keying tool located in the Blender Compositor. Its primary function is to remove a solid color background—typically green or blue—from video footage or rendered image sequences, generating a transparent alpha channel around the foreground subject.

Rather than requiring multiple individual nodes to extract color, refine edges, and clean up color reflection, the Keying node consolidates the entire green-screen workflow into a single, efficient operation.

Core Functions of the Keying Node

The Keying node performs several automated and adjustable processes simultaneously:

  • Key Color Extraction: By selecting the target color using the node's color picker, Blender detects the primary background color and converts those specific hue and saturation values into transparency.
  • Matte Generation: The node creates a high-contrast black-and-white matte (alpha channel), where pure white represents fully opaque foreground elements and pure black represents fully transparent background elements.
  • Matte Refinement (Clip Black and Clip White):
    • Clip Black: Increases the threshold for transparency, eliminating background noise, uneven lighting, and lingering artifacts.
    • Clip White: Ensures that translucent pixels inside the foreground subject become fully solid and opaque.
  • Automated Despill: Green-screen setups frequently cause green light to bounce onto the subject's skin, hair, and clothing. The Keying node automatically neutralizes this unwanted color fringe without requiring an external color correction node.
  • Edge Adjustment: Parameters like Dilate/Erode shrink or expand the boundaries of the extracted subject, while Feathering softens the edges to ensure a natural transition between the subject and the new background.

Why Use the Keying Node?

In standard compositing workflows, manually pulling a clean key can require chaining together Color Spill nodes, Matte nodes, and Blur filters. The Keying node streamlines this process by packaging these tools together, providing real-time feedback and high-quality edge retention for hair, motion blur, and semi-transparent objects directly inside Blender.
