How to Mirror a Shape Key in Blender

Mirroring a shape key in Blender allows 3D artists to quickly transfer facial expressions, corrective blend shapes, or mesh deformations from one side of a symmetrical model to the other. Whether you need to flip an existing shape key to the opposite side or create separate left and right controls from a single shape, Blender provides built-in tools to copy, mirror, and blend shape keys based on vertex indices or mesh topology.

Method 1: Mirroring a Shape Key to the Opposite Side

To duplicate a shape key (for example, transferring a expression from the left eye to the right eye), follow these steps:

  1. Select your mesh object in the viewport.
  2. Go to the Object Data Properties tab (the green triangle icon in the right-hand panel).
  3. Expand the Shape Keys section.
  4. Click on the shape key you want to mirror to highlight it.
  5. Click the downward-pointing arrow (Shape Key Specials menu) to the right of the shape key list.
  6. Select New Shape From Mix or Duplicate Shape Key to create a copy of the active shape key.
  7. Select the newly created duplicate shape key in the list.
  8. Click the downward-pointing arrow again.
  9. Choose Mirror Shape Key.

The mesh deformation will now be flipped across the local X-axis of the object.

Method 2: Using Topology Mirroring

If your mesh is visually symmetrical but its underlying vertex numbers (indices) are not ordered symmetrically, the standard Mirror Shape Key tool may distort your mesh. In this case, use topology mirroring:

  1. Follow steps 1 through 7 from Method 1 to create a duplicate shape key.
  2. Click the downward-pointing arrow (Shape Key Specials menu).
  3. Select Mirror Shape Key (Topology).

Blender will calculate the mirror action based on the physical spatial location of the vertices across the X-axis rather than their index order.

Method 3: Splitting a Symmetrical Shape Key into Left and Right

If you designed a shape key that affects both sides of the mesh simultaneously (such as a double eyebrow raise) and want to split it into separate left and right shape keys:

  1. Create a Vertex Group assigning a weight of 1.0 to the left side of the mesh and 0.0 to the right side.
  2. Select the full symmetrical shape key from the Shape Keys list.
  3. In the Vertex Group field located directly below the shape key list, select the left-side vertex group you created. This masks the shape key to only affect the left side.
  4. Click the downward-pointing arrow menu and select New Shape From Mix.
  5. Rename this new shape key (e.g., Eyebrow_Raise_L).
  6. To create the right side, clear the vertex group field, assign a right-side vertex group (or invert the weight), and repeat the New Shape From Mix step.

Important Requirements for Successful Mirroring

  • Origin Point: Ensure the object's origin point is centered along the axis of symmetry (typically X = 0).
  • Transformations: Apply object transforms before mirroring by pressing Ctrl + A in Object Mode and selecting All Transforms.
  • Axis Symmetry: Blender mirrors shape keys along the object's local X-axis by default. Ensure your model is facing front along the Y-axis or Z-axis appropriately.
