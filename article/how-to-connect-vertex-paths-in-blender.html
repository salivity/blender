How to Connect Vertex Paths in Blender

Connecting vertex paths in Blender is a fundamental skill for 3D modeling, allowing you to join endpoints, split faces, or merge separate geometry into continuous lines and meshes. This guide covers the most efficient techniques to connect vertices in Blender's Edit Mode, including using the Fill key (F), the Connect Vertex Path tool (J), merging vertices (M), and joining curve paths.

1. Connect Vertices with a New Edge (F Key)

To connect two separate vertices or create a bridge between the ends of two vertex paths, use the Fill command:

  1. Select your object and press Tab to enter Edit Mode.
  2. Press 1 on your keyboard to switch to Vertex Select mode.
  3. Hold Shift and right-click (or left-click, depending on your keymap) to select the two vertices you want to connect.
  4. Press F.

Blender will draw a new edge directly between the selected vertices. You can also select multiple vertices in sequence and press F repeatedly to extend a vertex path step-by-step.

2. Split Existing Geometry Between Vertices (J Key)

If you want to connect two vertices across an existing face and cut through the geometry, use the Connect Vertex Path tool instead of Fill:

  1. In Edit Mode, select two vertices that share a common face.
  2. Press J.

Unlike the F key—which simply places an overlapping edge on top of the mesh—the J key splits the intervening face into new faces and connects the vertices cleanly into the topology.

3. Merge Vertices into a Single Point (M Key)

If "connecting" means collapsing two vertex path endpoints into a single point, use the Merge menu:

  1. Select the vertices you wish to join.
  2. Press M to open the Merge menu.
  3. Choose your preferred merge method:
    • At Center: Merges all selected vertices at their geometric midpoint.
    • At First / At Last: Merges the selection at the position of the first or last vertex selected.
    • By Distance: Merges vertices that are within a specified distance threshold of each other (useful for cleaning up overlapping paths).

4. Bridge Edge Loops for Parallel Vertex Paths

To connect two parallel paths consisting of multiple vertices:

  1. Select both paths in Edit Mode.
  2. Right-click on the viewport to open the Vertex Context Menu.
  3. Select Bridge Edge Loops (or access it via the top menu: Edge > Bridge Edge Loops).

This creates a series of quad faces connecting the two vertex paths seamlessly.

5. Connecting Paths in Curve Objects

If you are working with Curve objects rather than standard meshes:

  1. Enter Edit Mode on the curve object.
  2. Select the two end control points of the open paths.
  3. Press F to create a segment connecting the two points, or press Alt + C (or Toggle Cyclic in the Curve menu) to close the entire curve path.
