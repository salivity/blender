How to Convert Triangles to Quads in Blender

Converting triangles (tris) to quadrilaterals (quads) in Blender is essential for creating clean topology, improving deformation during animation, and making Subdivision Surface modifiers work effectively. Blender offers a quick, built-in feature called "Tris to Quads" that automatically merges adjacent triangular faces into four-sided polygons. This guide covers the primary keyboard shortcut, menu options, and settings to clean up your 3D mesh quickly.

Method 1: Using the Keyboard Shortcut (Alt + J)

  1. Select your 3D object and press Tab to enter Edit Mode.
  2. Press 3 to switch to Face Select Mode (or 1 for Vertex Mode).
  3. Select the faces you want to convert. To convert the entire mesh, press A to select all.
  4. Press Alt + J on your keyboard. Blender will instantly convert adjacent triangles into quads.

Method 2: Using the Face Menu

  1. Switch to Edit Mode (Tab).
  2. Select the desired geometry (A for the full mesh).
  3. Click on Face in the top menu bar of the 3D Viewport.
  4. Select Tris to Quads from the dropdown menu.

Adjusting the Conversion Settings

Directly after running the command, an operator box labeled Tris to Quads will appear in the bottom-left corner of the 3D Viewport (or press F9 to open it). You can adjust these settings to fine-tune the result:

  • Max Angle: Determines the maximum allowed angle between adjacent triangles for them to join. Increasing this converts more tris, but it may create skewed or non-planar quads.
  • Compare UVs: Prevents merging if it breaks existing UV texture mapping.
  • Compare Materials: Prevents merging triangles that have different materials assigned.
  • Compare Seams / Sharp: Prevents merging across defined UV seams or sharp edges.

Alternative: Quadriflow Remesh for Sculpted Models

If you are working with a dense, sculpted mesh where Alt + J leaves too many uneven faces, use the automated remesher:

  1. Select the object in Object Mode.
  2. Go to the Object Data Properties tab (green triangle icon) in the right panel.
  3. Expand the Remesh section.
  4. Select Quad and click Quadriflow Remesh.
  5. Set the target number of faces and click OK to generate a clean, quad-based topology.
