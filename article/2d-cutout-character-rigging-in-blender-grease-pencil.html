2D Cutout Character Rigging in Blender Grease Pencil

This guide covers the end-to-end process of building a modular 2D cutout character rig using Blender's Grease Pencil and Armature systems. You will learn how to structure individual body parts across separate layers, align joint pivot points, generate a functional skeletal armature, parent your 2D artwork directly to bones, and establish inverse kinematics (IK) for efficient 2D animation.

1. Create and Separate Character Artwork

  1. Open Blender and create a 2D Animation workspace.
  2. In the Draw Mode of your Grease Pencil object, draw your character divided into distinct anatomical parts (e.g., Head, Torso, Upper Arm, Forearm, Hand, Thigh, Shin, Foot).
  3. Ensure each body part exists on its own dedicated Grease Pencil Layer in the Object Data Properties panel (Properties > Data > Layers).
  4. Overlap the joint areas (such as elbows and knees) with rounded caps to prevent gaps from appearing when limbs rotate.

2. Adjust Layer Offsets and Draw Order

  1. In the Layers panel, arrange the layer stack so that foreground elements (like the front arm) sit above the torso, and background elements (like the back arm) sit below it.
  2. If using multiple Grease Pencil objects instead of layers, adjust the Y-axis position slightly in the 3D viewport (e.g., move front limbs forward by 0.001m and back limbs backward by -0.001m) to avoid Z-fighting.

3. Create the Armature Hierarchy

  1. Switch to Object Mode.
  2. Press Shift + A and select Armature > Single Bone.
  3. In the Armature Properties, go to Viewport Display and check In Front to keep bones visible over your artwork.
  4. Select the armature, enter Edit Mode (Tab), and align the root bone with the character's hips or torso.
  5. Extrude (E) new bones from the joints to match the rest of the character's structure (spine, neck, head, arms, and legs).
  6. In the Bone Properties tab, name every bone clearly (e.g., Arm_Upper.L, Arm_Lower.L, Hand.L).

4. Parent Artwork to Bones

Method A: Single Multi-Layer Grease Pencil Object (Recommended)

  1. Select the Grease Pencil object, hold Shift, and select the Armature.
  2. Press Ctrl + P and choose With Empty Groups.
  3. Select the Grease Pencil object and open the Object Data Properties panel.
  4. In the Layers sub-panel, expand each layer and assign the corresponding bone name in the Parent / Relations field, or assign the layer's strokes to the matching Vertex Group using weight painting/assign tools.

Method B: Separate Grease Pencil Objects

  1. Switch the Armature into Pose Mode.
  2. Select an individual Grease Pencil object (e.g., the forearm), hold Shift, and click the specific bone it belongs to.
  3. Press Ctrl + P and select Bone.
  4. Repeat this step for each individual body part.

5. Set Up Inverse Kinematics (IK)

  1. Select the Armature and enter Pose Mode.
  2. Select the lower limb bone (e.g., Arm_Lower.L or Leg_Lower.L).
  3. Go to the Bone Constraints tab and add an Inverse Kinematics constraint.
  4. Set the Target to the character's Armature and choose a newly extruded, unparented controller bone (e.g., Hand_IK.L or Foot_IK.L) as the Bone target.
  5. Set the Chain Length to 2 so the movement only influences the lower and upper limb segments without affecting the rest of the spine.

6. Test and Refine the Rig

  1. In Pose Mode, select your controller bones and press G to move or R to rotate.
  2. Check the joints for visual tearing; if needed, switch back to Draw Mode or Edit Mode on the Grease Pencil object to adjust the rounded stroke caps at the pivot axes.
  3. Lock any unused transform channels (such as location/scale on rotational joints) in the Transform panel to keep the rig user-friendly during animation.
