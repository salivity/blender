What is the Box Select Tool in Blender?

The Box Select tool in Blender is a fundamental selection feature that allows users to select multiple objects, vertices, edges, faces, or keyframes by drawing a rectangular boundary around them. It is one of the fastest and most efficient ways to manipulate groups of elements in both 3D viewports and 2D editors like the Dope Sheet or UV Editor. This guide covers how the tool works, how to activate it, essential keyboard shortcuts, and tips for selecting hidden geometry.

How to Activate the Box Select Tool

You can activate the Box Select tool using a few simple methods:

  • Keyboard Shortcut: Press the B key on your keyboard while hovering over a viewport or editor window. Your cursor will change to a crosshair with dashed lines, indicating that Box Select is active.
  • Toolbar Icon: Click the Selection Tool icon at the top of the left-hand Toolbar (press T to toggle the toolbar if it is hidden) and choose Select Box from the dropdown menu.
  • Default Left-Click Drag: By default in modern Blender versions, clicking and dragging the left mouse button in empty space activates a box selection automatically.

How to Use Box Select

Once the tool is activated, follow these actions to perform different types of selections:

  1. New Selection: Left-click and drag across the screen to create a rectangular box. All items within or intersecting the box will be selected, replacing any previous selection.
  2. Add to Selection: Hold Shift while drawing the box to add the enclosed elements to your current selection without deselecting existing items.
  3. Deselect Elements: Hold Ctrl (or Cmd on macOS) while drawing the box to remove elements inside the rectangle from your active selection.

Selecting Hidden Geometry with X-Ray Mode

By default in Edit Mode, the Box Select tool only highlights elements visible from your current viewport angle. Vertices, edges, or faces located on the back side of a 3D mesh are ignored.

To select through the entire mesh:

  1. Enable X-Ray Mode by pressing Alt + Z (or clicking the dual-square icon in the top right of the 3D Viewport).
  2. Use the Box Select tool (B).
  3. All geometry inside the box—both front-facing and occluded—will now be selected.

Applications Across Different Blender Editors

The Box Select tool functions consistently throughout Blender's interface:

  • 3D Viewport (Object Mode): Quick selection of multiple 3D models, lights, or cameras.
  • 3D Viewport (Edit Mode): Bulk selection of geometry for modeling, transforming, or assigning materials.
  • UV Editor: Grouping and moving UV islands or individual UV vertices.
  • Dope Sheet / Graph Editor: Dragging a box around multiple keyframes to move, scale, or delete animation data simultaneously.
