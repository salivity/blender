How to Use Median Point Pivot in Blender

The Median Point pivot point in Blender calculates the exact average center location of all selected objects, vertices, edges, or faces to perform transformations like scaling and rotation. This guide covers what the Median Point pivot is, how to activate it using interface menus or keyboard shortcuts, and practical steps for using it effectively in both Object Mode and Edit Mode.

What is the Median Point Pivot?

In Blender, the Pivot Point determines the origin location around which objects or mesh elements rotate, scale, or mirror. The Median Point option calculates the arithmetic mean (average position) of all selected elements. If you select three objects, the transform center will sit at the precise mathematical midpoint between all three origins.

How to Enable the Median Point Pivot

You can set your pivot point to Median Point using either the top interface menu or a quick keyboard shortcut:

Method 1: The Viewport Header Menu

  1. Look at the top center of the 3D Viewport.
  2. Click the Transform Pivot Point icon located next to the Snapping options.
  3. Select Median Point from the drop-down menu.

Method 2: Keyboard Shortcut

  1. Hover your mouse cursor over the 3D Viewport.
  2. Press the Period key (.) on your keyboard to open the Pivot Point Pie Menu.
  3. Select Median Point from the wheel menu.

Using Median Point in Object Mode

When working with multiple separate objects in Object Mode:

  1. Select two or more objects by holding Shift and right-clicking/left-clicking each object.
  2. Press R to rotate, S to scale, or G to move.
  3. The transformation applies around the shared central point of all selected objects' origins. Rotating will cause the objects to orbit around this collective center rather than spinning individually.

Using Median Point in Edit Mode

When editing a mesh's geometry:

  1. Select your object and press Tab to enter Edit Mode.
  2. Select the vertices, edges, or faces you want to modify.
  3. Press R to rotate or S to scale.
  4. The transformation centers around the average position of all selected geometry. For example, selecting two opposite faces on a cube and scaling them down will pull both faces inward toward the center of the cube.

Difference Between Median Point and Bounding Box Center

  • Median Point: Accounts for every single selected item or component. If a mesh has a dense cluster of vertices on one side, the median point pulls closer to that dense cluster.
  • Bounding Box Center: Ignores geometry density and calculates the center strictly based on the outermost boundaries (X, Y, Z limits) of the selection.
